图表 Chart

先判断数据关系，再选图形类型：趋势用折线 / 曲线，离散比较用柱状，构成用饼 / 环 / 百分比，多维比较用雷达，单目标达成用仪表或进度，关键词热度用词云。同一页面保持颜色映射稳定，不用临时颜色替代图表色。

图表配色规则Color

所有图表共同的前置规则：先建立稳定的系列映射，再进入具体图表；状态语义色不占用系列色序列。

系列色板

按数据系列出现顺序，从 CH01 开始依次取色，超过 10 个循环。

映射原则

颜色服务于识别和比较，不单独承担数据含义。

依次取色系列从 CH01 开始依次使用，不跳号，不按图表类型另建临时色。
映射稳定同一指标在图表、图例和交互状态中保持同一颜色。
语义分离上涨、下跌、持平用 Feedback 色（error&rise / success&decline / plain），不占用 CH 序列。
不只靠颜色两个及以上系列必须有图例或标注保留系列名称。
字体图上的数据数字（坐标、柱顶 / 扇区标签、图例数值）用普通 UI 字体 Regular，不加粗；数字字体只用于指标卡和需要突出的关键数值（如环形中心总量、仪表完成率、进度列表数值）。

使用建议

设计与交互建议。

主题推荐做法边界与避免
刻度Y 轴 4–6 个刻度，取整齐步长；有单位时写在左上方，刻度只写数字。不出现 13.7 这类刻度，不在每个刻度后重复单位。
起点柱状图数值轴从 0 开始；折线图截断坐标轴时标清范围。不通过截断放大差异。
方向时间趋势、纵向柱状用横向网格；类目名称较长或排行对比用条形图 + 纵向网格。同一图表不同时画横竖两组网格。
X 标签标签过密时抽样显示，首末标签贴边对齐。不缩小字号、不旋转标签。
图例两个及以上系列显示图例，折线 / 柱状放在图表上方；可点图例隐藏系列，隐藏态名称 40%，热区不小于 44。单系列不加图例；图例不压在图形上；至少保留一个系列。
数据指示器点按 / 拖动绘图区出现并吸附最近数据点，抬手保持；选中日期与各系列数值同步显示在图例或数据卡片上。不常驻显示；不遮挡数值；隐藏的系列不显示节点。
无数据无数据或加载失败时改用空状态组件。不保留空坐标系。

折线图Line

用直线连接相邻数据，适合观察阶段变化、转折和多个指标之间的差异。分 Default（仅折线）与 Fill（折线 + 渐变面积）两种风格。

单指标 · Fill
多指标 · Default
单指标一条 CH01 折线，可加同色渐变面积（最高点 30% → 底部 0%）强调量感；不加图例，由标题说明。
多指标1–5 条，按 CH01、CH02… 依次取色，图表上方加图例；Fill 只用于 1–2 条，3 条及以上用 Default。所有面积在下、折线在上。
线型线宽 2，尖角转折、端点平头，不加数据点，不做平滑处理。超过 5 条拆图或改为选择后查看。

曲线图Curve

用平滑曲线表现连续趋势，适合强调变化平滑性的场景，如客户增长、流量波动。样式、取色、风格与折线图一致。

单指标 · Fill
多指标 · Default
平滑方式单调三次插值，曲线经过每个数据点，不越过相邻点的高低范围，不制造原数据没有的波峰波谷。
何时不用数据有突变、需要读出转折点时用折线图；不用平滑掩盖真实突变。
基座path.gj-m-chart-line / path.gj-m-chart-area，与折线共用类名，只是路径为曲线。

柱状图Bar

比较离散类别；支持纵向、横向，单系列、分组、堆叠和正负值。

纵向 · 分组
横向 · 正负值（涨跌）
纵向 · 单系列 · 数值标签
纵向 · 堆叠
柱宽与圆角单系列柱宽 16；分组每柱 12、组内间距 4；堆叠柱宽 16、分段间距 2。圆角统一 4。类目在绘图区内平均分布；放不下时柱宽收窄，单柱最小 8。

环形 · 160 · 图例右侧带数值
饼图 · 180 · 图例下方

单项完成 · 多段构成 · 高 8
