使用建议

设计与交互建议。

主题推荐做法边界与避免
排列名称短、内容短时用两端对齐；名称长短不一、需要对齐阅读时用左对齐；内容很长时用纵向。同一张卡片里不混用排列方式。
宫格字段多且内容短（数值、状态）时用两列宫格，放在卡片内；只显示一行，超出用 … 省略。可能超过一行的重要内容不放进宫格。
名称简短明确；需要解释口径时加信息图标。名称不换行，过长时缩短措辞。
多行列表中内容过长自动换行，名称与内容按顶部对齐；数值保持统一精度和单位。列表中不截断关键信息。
分割线字段多、需要逐行比对时带分割线（上下 12）；字段少、整体较轻时可不带分割线（上下 4）。同一张卡片里不混用。
无数据统一显示“--”。不用 0 或留空代替。
