常见用法

图标、文件信息和操作区可独立选择。文件名保留扩展名；图标始终对齐首行标题。

选用建议

用于详情页、信息页中的已有附件；按用户权限和文件能力提供操作。

主题推荐做法边界与避免
使用场景展示已有文件，按业务提供查看、分享、下载。文件选择、上传进度与失败反馈使用上传组件。
纵向排列相邻文件项间距为0，靠行内padding保持阅读节奏。页面外边距由容器提供，不重复叠加。
名称与信息文件名保留扩展名，长主名省略；完整名称保留。创建人、大小按需要展示。不以文件大小或创建信息替代文件名。
图标使用对应文件类型图标，与第一行标题对齐；上下文明确时可隐藏。不按文件名猜测文件可预览能力。
操作选择优先展示高频且有权限的动作；较多操作收进业务明确的更多菜单。不提供无权限或不支持的动作；分享须确认可分享范围。
状态反馈真实页面提供预览加载、下载进度及失败重试反馈。当前组件演示仅提示操作名称，不实现文件服务。
