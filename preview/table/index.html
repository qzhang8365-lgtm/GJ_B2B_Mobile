数据展示组件 · Data Display

表格 Table

结构化展示多条同类数据，支持字段比较、排序、选择和单行操作。

类型

按承载场景选择页面内普通表格或弹出层表格；两种都保留字段标题和必要的操作入口。

普通表格 · 可完整展示，操作列无投影
弹出层表格 · 内容超出可横向滑动，操作列出现投影

表头与单元格

表头高 46、Table/head_bg 底、Text/Secondary；单元格上下 12、左右 16，单行 46 / 双行 68，底部 1px 分割线；文字 P3 14/22。

表头 · 默认 / 排序 / 勾选 / 说明图标
单元格 · 单行 / 双行 / 勾选 / 操作

表格操作

操作列放最右侧并始终固定，有内容被遮住时左侧出现投影；优先展示 1–2 个高频动作；表头勾选按勾选组件的未选 / 选中 / 半选显示；勾选后批量操作放在表格上方。

行内操作 · 勾选与半选

交互演示

点「可用资金」排序（升序 → 降序 → 取消）；勾选行后上方出现批量操作；点「切换」打开弹出层表格选择账户；表格可左右滑动，操作列始终固定；有内容被操作列遮住时才出现投影，滑到最右或字段能完整展示时没有投影。

属性控制

使用建议

优先保证关键字段与操作可读，不直接压缩桌面端的全部列。

主题推荐做法边界与避免
字段优先展示 3–4 个关键字段；更多字段横向滚动、折叠或进入详情。不把桌面端全部列压缩进一屏。
单元格主要内容用单行；需要补充信息时用双行（如编号 + 手机号）。不超过两行，超出用省略或进详情。
对齐文本默认左对齐；同列数据格式和精度一致，需要比较大小时数值可右对齐。同一列不混用对齐方式。
排序只有真正支持排序的字段显示排序图标，并显示当前方向。不给不可排序的字段加图标。
操作操作列放最右侧并始终固定，保留 1–2 个高频动作，其余收进“更多”。删除等高风险操作用危险语义并二次确认；不可用操作说明原因。
批量勾选后在表格上方显示批量入口和已选数量。不在每行重复放批量入口。
可访问性表头用 th scope="col"；排序表头写 aria-sort；勾选框写“选择××”；排序、说明、操作热区不小于 44。—
