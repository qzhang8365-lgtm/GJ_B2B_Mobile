开关 Switch

控制单一功能或设置的开启与关闭，操作后通常立即生效，并持续反映当前的开 / 关状态。

尺寸

Default 用于常规设置页，Small 只用于紧凑列表；放在列表行内时整行可点。

交互演示

点击开关或整行切换，立即生效。勾选“模拟请求失败”后，切换会先进入请求中（不可再点），失败后恢复原状态并提示。

使用建议

设计与交互建议。

主题推荐做法边界与避免
适用范围只用于明确的开 / 关状态。不用于多个互斥选项、内容视图或筛选条件切换；切换互斥内容或模式用分段控制。
标签描述被控制的功能，如“消息通知”“自动保存”。不写含义不完整的“开关”，也不重复写“开启 / 关闭”。
生效时机切换后立即生效。变更不可逆、风险高或需要提交审核时，改用按钮与确认流程。
请求反馈涉及网络请求时提供请求中与失败反馈；失败后恢复原状态。不让界面与实际状态不一致。
禁用有明确业务原因；必要时在附近提供说明或权限入口。不只靠降低透明度表达。
尺寸Default 用于常规设置页；Small 只用于紧凑列表，且整行可点。同一列表不混用两种尺寸。
