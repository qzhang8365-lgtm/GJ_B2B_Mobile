徽标 Badge

附在图标、入口或列表项上，提示数量或有新内容。

类型与尺寸

需要具体数量用数字徽标，只提示有新内容用红点。一位数为圆形，多位数自动加宽，超过 99 显示 99+。

红点 / 数字（默认 16、大号 20）
描边：用在有色或复杂背景上

使用位置

徽标中心对齐承载对象右上角：单个图标对齐图标本身，带底色的入口对齐底块；列表项放在行尾。

图标 / 入口右上角
列表项行尾

交互演示

工作台首页：导航栏通知、金刚区入口、消息列表和底部导航都带徽标。调整未读数量；点开消息或入口后徽标减少或消失。

属性控制

使用建议

设计与交互建议。

主题推荐做法边界与避免
选用需要数量用数字徽标；只提示“有新内容”用红点。同一含义固定一种形式。不承载核心业务数据，能独立阅读的信息用文本或标签。
上限统一超限规则，超过 99 显示 99+，避免位数增长导致布局抖动。—
位置附在承载对象右上角或列表行尾，同一列表中位置、间距一致。不遮挡关键图形或文字，不独立悬浮。
颜色默认红底白字；有色或复杂背景加描边。不只靠颜色区分重要状态。
更新已读、处理完成后及时减少或隐藏；数量为 0 时不显示。—
交互与读屏点击由承载对象响应；在承载对象上说明含义与数量（如“消息，3 条未读”）。徽标本身一般不做独立点击入口。
