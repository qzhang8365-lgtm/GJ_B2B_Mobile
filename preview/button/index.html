按钮 Button

用于触发操作的按钮族，包含按钮、文字按钮与悬浮按钮。图标只从图标库选取，颜色始终与按钮文字（或前景色）一致。

按钮Button

用于触发即时操作、提交任务或推进流程。层级表达操作权重，尺寸取决于所在容器。

操作层级

同一操作区域保留一个最明确的主操作，其余按钮依次降低视觉权重。Ghost 为浅灰底、无描边的最轻操作。

Tertiary / Ghost

尺寸与图标

默认使用 Medium；同一操作组保持相同尺寸。图标尺寸与圆角随档位变化。

Medium · 32 · 图标 16 · 圆角 6

形状

Shape 分 regular 与 pill。pill 为全圆角（Radius-full），其余尺寸与 regular 相同。

Large · regular · 圆角 8
Large · pill · 全圆角

状态

移动端包含 default、pressed、disabled，没有 hover。各层级的 disabled 表现不同：Primary 换浅色底，Tertiary 文字变灰，Secondary 与 Ghost 整体透明度 40%。

组合使用

多个按钮组合时，横向、纵向间距通常为 8，大按钮 12，小按钮 4，可按场景调整。通栏按钮宽度依据页面边距撑满容器。

属性控制

选用规则

按钮主要用于操作；规范页明确提供多层级按钮表达选中状态的组合案例。

主题推荐做法边界与避免
层级主操作用 Primary，同一区块尽量只出现一个；次操作 Secondary，弱操作 Tertiary 或 Ghost。并排按钮避免相同视觉权重。
尺寸默认 Medium；页面主操作与表单用 Large；卡片或列表内紧凑操作用 Small。同一行按钮同档。主操作按钮实际高度不低于 40px。
图标只从图标库选取，用 .gj-icon 引用；图标颜色跟随按钮文字色。不得自绘图标、使用 Emoji，或单独给图标设色。
纯图标按钮正方形，图标含义明确时使用，并提供 aria-label。含义不清时改用图标加文字。
文字文案简短，说明操作结果。按钮文字不省略、不换行；空间不足时调整按钮组排布。
热区实际点击区域至少 44×44px。不为扩大热区改变按钮视觉尺寸。

文字按钮Text Button

无背景、无描边的轻量操作，用于查看详情、展开更多或卡片、列表行内的次要操作。

基础用法

Style 分 grey 与 blue：grey 用于一般轻量操作，blue 用于需要强调的链接式操作。图标可放在文字左侧或右侧，没有纯图标形态。

grey · None / Left_Icon / Right_Icon
blue · None / Left_Icon / Right_Icon

尺寸与图标

无内边距，高度等于文字行高；图标与文字间距 4。默认使用 Medium，与并排控件保持同档。

Large · 16/24 · 图标 20
Medium · 14/22 · 图标 16
Small · 12/18 · 图标 12

状态

移动端包含 default、pressed、disabled，没有 hover。文字与图标同步变色：grey 依次为 Text/Secondary、Text/Primary、Text/disable；blue 依次为主按钮底色的默认、按下、禁用三色。

组合使用

文字按钮适合放在卡片标题行、列表行尾或 Button 旁作为更弱的操作。

卡片标题行 · Medium
与 Button 并排 · Small

属性控制

选用规则

文字按钮只承担轻量操作，不替代主操作或导航。

主题推荐做法边界与避免
用途查看详情、展开更多、卡片或列表行内的次要操作。页面主操作、需要明确权重的操作改用 Button。
尺寸默认 Medium；与 Button 或其他控件并排时保持同档。同一行不混用尺寸。
图标只从图标库选取；跳转、展开类用右侧箭头，动作类用左侧图标；颜色跟随文字。不得自绘图标或单独给图标设色；没有纯图标形态。
文字文案简短，说明操作结果。不省略、不换行。
热区实际点击区域至少 44×44px；相邻文字按钮留足间距。不为扩大热区改变视觉尺寸。

悬浮按钮Floating Button

固定在界面右下方、带投影的圆形按钮。用于页面内容过长时快捷回到顶部或到达底部，也可按需承载新增内容、发帖、下载等页面级操作。

配色与方向

48×48 圆形，图标 28，投影 Shadow_center。default 白底灰色图标，用于回到顶部等辅助操作；blue 品牌蓝底白色图标，用于页面主推操作。按下时 default 叠加黑 3%，blue 底色加深；无禁用态。

default · to_top / to_bottom / pressed
blue · to_top / to_bottom / pressed

承载其他操作

按需从图标库换用图标承载新增、发帖、下载等操作，图标颜色随配色变化。悬浮按钮只放图标，需提供 aria-label。

位置

固定在右下角，多个按钮纵向排列。有底部 TabBar 或操作栏时上移，不遮挡栏内操作。可在预览中滚动页面，点击按钮回到顶部或到达底部。

长列表 · 回到顶部 / 到达底部
有底部 TabBar · 新增 + 回到顶部

属性控制

选用规则

悬浮按钮只承载页面级的单一高频操作。

主题推荐做法边界与避免
用途长页面回到顶部 / 到达底部；按需承载新增、发帖、下载等页面级操作。不承载需要文字说明的操作，不用于表单提交。
配色辅助性的回到顶部、到达底部用 default；页面主推操作用 blue。同一页面不出现两个 blue。
数量同一页面不超过两个，纵向排列。不堆叠多个操作代替菜单。
位置右下角固定；有底部 TabBar 或操作栏时上移，避开安全区。不遮挡关键内容与栏内操作；列表末尾留出空白。
出现时机回到顶部在页面滚动超过一屏左右后出现，回到顶部后隐藏。内容不足一屏时不显示。
图标只从图标库选取；颜色随配色变化，提供 aria-label。不自绘图标、不单独给图标设色。
