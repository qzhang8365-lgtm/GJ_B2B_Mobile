Markdown 文章 Markdown Article

用于移动端文章、研报、知识库与上传内容的 Markdown 渲染。元素样式与 AI 对话中的 Markdown 共用，文章容器独立成页。

文章示例

Figma Markdown / Article：容器上下 24、左右 16，块间距 16；正文 16/24，H1 20/30、H2 18/26、H3 16/24。

H5 · 375 × 720 · 在预览内滚动

属性控制

输入后自动渲染；本地处理，不上传内容。

支持的语法
  • 标题 H1–H6
  • 段落
  • 加粗
  • 链接
  • 行内代码
  • 无序 / 有序列表（两级）
  • 任务列表
  • 引用
  • 代码块
  • 表格
  • 分割线
  • 图片与图注

原始 HTML 一律转义；图片只接受 http(s) 地址，失败显示占位。

使用规则

元素级规格见 AI 对话流的 Markdown 说明；此处只写文章容器的差异。

主题推荐做法边界与避免
容器.gj-m-markdown.gj-m-markdown-article：白底，上下 24、左右 16（页面边距）；块与块间距 16。不把文章正文放进卡片再叠加卡片内边距；不在文章中嵌套卡片。
字号正文 16/24；H1 20/30、H2 18/26、H3 及以下 16/24，加粗。标题到下方段落 8。对话气泡内正文行高 28（对话场景），文章用 24，不混用。
宽内容表格、代码块超宽时横向滚动并显示滚动指示条；表格单元格最多 4 行，超出加宽列。不缩小字号塞进屏宽；不让整页横向滚动。
图片图片 16:9 圆角，图注 14/22 二级文字；加载失败显示占位。只接受 http(s) 地址；不嵌入原始 HTML。
