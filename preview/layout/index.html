布局 Layout

通过屏幕宽度适配、栏栅格与间距体系共同控制移动端页面的信息密度与空间秩序。以 375×812 为设计基准，375 不是固定页面宽度。根字号按 min(100vw / 3.75, 120px) 随屏宽缩放，450px 起封顶；宽屏宽度撑满，通过增加列数承载更多信息，而不是继续放大组件。
