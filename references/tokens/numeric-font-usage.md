# 数字字体使用场景

来源：设计方于2026-10-19补充确认。适用于移动端页面生成与检查；不改变既有字号、行高、字重或Token数值。

## 优先级

先查具体组件的rules.md及已规定的文字样式。组件已明确使用或不使用数字字体时，以组件规则为优先；以下为其它场景的默认生成规则。不因内容包含数字就覆盖组件字体。

## 默认使用GJType

1. 股票代码、基金代码、金融产品代码等代码字段。保留前导零、字母后缀及原始格式，不作为数值转换。
2. 独立呈现的重要数据、金额、价格、百分比、涨跌幅等数字字段。根据层级选用现有N系列数字样式，不自行放大或加粗。

## 不优先使用GJType

文本、段落内出现的数字随所在文字使用系统字体，包括文章正文、卡片标题、摘要、标签、“为您找到 x 条信息”等句式，以及日期和日期时间。不要拆出其中的数字单独套用数字字体；日期不因独立展示就自动套用数字字体。组件有明确数字字体规定时仍遵循组件规则。

## 实现与检查

- 数字字体引用`--ds-font-family-numeric`（GJType，加载失败回退系统字体），文本字体引用`--ds-font-family-ui`。
- 金额、价格、涨跌幅等纵向对齐或连续刷新的字段按需加`font-variant-numeric: tabular-nums`；等宽数字排版与字体选型是两个维度，不能据此把文本数字全部改用GJType。
- 生成后检查股票/基金代码的前导零、价格与百分比格式、组件字体优先级，以及标题、标签、日期和句内数字是否保持所在文本字体。
