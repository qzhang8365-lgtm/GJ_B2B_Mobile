# 生成速查（移动端 H5）

生成页面时先看这页；数值都以 375 基准写出。需要原因、例外或完整表格时再读原文：`h5-sizing-and-adaptation.md`、`h5-control-sizing.md`、`h5-radius-and-containers.md`、`h5-small-screen.md`。页面基础写法（引入样式、根字号、盒模型）见 `components/MAPPING.md`。

## 换算与宽度

- `html{font-size:min(calc(100vw / 3.75),120px)}`：375 时 1rem = 100px，设计值 ÷ 100 写 rem（16 → `.16rem`）；450 起封顶。
- 不缩放：1px 边框 / 分割线、44 热区、导航栏 44、根字号上限 120、≥960 内容区最大 960。
- 分档：320–359 小屏（`@media (max-width:359px)` 兜底）｜360–449 等比｜450–599 封顶流式｜600–959 改多列｜≥960 居中 960、卡片三列。
- 验收宽度：375 / 320 / 768。

## 间距（只用语义变量 `--space-<token>`）

| 用途 | Token | 值 |
| --- | --- | --- |
| 页面左右边距 | `page-margin-x` | 16（小屏下限 `max(.16rem,12px)`） |
| 模块之间 / 模块标题 → 卡片 | `module-gap` / `module-title-gap` | 24 / 12 |
| 一级卡片：内边距 / 卡片之间 / 标题 → 内容 / 分区之间 | `card-l1-padding` / `-gap` / `-title-gap` / `-section-gap` | 16 / 12 / 12 / 16 |
| 0 级卡片：外边距 / 内边距 | `card-l0-margin-x` / `card-l0-padding` | 0 / 16 |
| 二级卡片：内边距 / 之间 / 标题 → 内容 / 分区 | `card-l2-*` | 12 / 8 / 8 / 12 |
| 三级块：内边距 / 之间 | `block-l3-*` | 8 / 8 |
| 强绑定 / 同组元素 | `stack-tight` / `stack-default` | 4 / 8 |
| 图标与文字 / 标签之间 | `inline-icon-gap` / `inline-tag-gap-min|max` | 4 / 4–8 |
| 并排按钮 / 底部双按钮 | `btn-gap` / `btn-gap-footer` | 8 / 12 |

阶梯只有 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48。同组 < 组间 ≤ 容器内边距；嵌套一层降一档（16 → 12 → 8）。容器留白只算一次，按视觉边缘量（PR-007 / 013）。

一级卡片结构按 PR-029 选用：复杂内容标准头部到内容16；周期摘要、简短说明用 `gj-m-card-compact`，头部到内容8、相关信息行距4。四周16、圆角12、卡片间距12不变。仅标题+单一操作用同行header（Small按钮），不建空body；展开/收起可放标题右侧。避免父gap与子margin叠加。

## 控件高度（`--control-*`，用 min-height）

| 档 | 值 | 用途 |
| --- | --- | --- |
| XXS / XS | 20 / 24 | 标签 S / M、文字按钮 |
| S | 28 | 按钮 S、卡片内紧凑操作与输入 |
| M | 32 | 按钮 M、卡片操作、搜索框与筛选区 |
| ML | 36 | 独立控件（如分段控制） |
| L | 40 | 按钮 L、页面主操作、表单输入 |
| XL / XXL | 44 / 48 | 关键主操作（登录、确认交易）/ 营销 CTA |

同一行控件同档；热区 ≥ 44×44，由组件伪元素扩展，不撑大布局（PR-010）。

## 圆角

0 级卡片、弹窗 16（`--Radius-XL`）｜一级卡片、卡片模式列表 12（`--Radius-LG`）｜二级卡片、同行 >3 的小卡片 8（`--Radius-MD`）｜三级块、标签 4（`--Radius-XS`）｜控件 S / M 6（`--Radius-SM`）、L 及以上 8｜头像、胶囊 `--Radius-full`。

## 字号下限与文字

- 正文 ≥ 12（小屏用 `max(rem,12px)`，前面先写纯 rem），辅助文字、Small 标签、底部导航标签 ≥ 10。
- 输入框按设计字号（L 16 / M 14）。H5 / web-view 页面只要有输入框就在 viewport 加 `maximum-scale=1`：rem 随屏宽缩小，L 输入在 320 宽也只有约 14，同样会触发 iOS 聚焦放大；小程序原生页面不处理。
- 标题单行省略，描述最多 2 行；按钮文字不省略不换行；标签不省略、最多 2 行。省略元素的 flex 父项 `min-width:0`。
- 金融数字 `font-variant-numeric: tabular-nums`，不截断、不在数值中间折行；≥1 万显示“万”、≥1 亿显示“亿”。

## 固定栏与安全区

- 自绘底部导航内容高 `.56rem`（热区 ≥ 44），安全区另加 `env(safe-area-inset-bottom)`；正文底部预留栏高 + 安全区。
- 固定底栏：白底，上下 12、左右 16 + 安全区，顶部 1px `Border/default`。
- 弹窗、浮层用 `position:fixed` 外层容器，打开时锁定背景滚动，关闭后焦点回到触发控件。

## 容器

小程序原生页面不自绘顶部导航与 TabBar；H5 / web-view 自绘。底部导航首页最左、个人入口最右，二级页面不显示。

## 标签背景
非白色背景（含灰底二级卡片）上的标签使用filled=true；白底按层级选风格，尺寸仍按PR-005（PR-030）。

操作按钮尺寸（PR-031）：卡片内默认Medium；紧凑卡片与信息同行Small；Large用于大卡片通栏、底部等重点操作。

卡片信息行（PR-032）：字段名与值优先同字号、同行高，用颜色区分，不将字段名单独套辅助文字字号。

参考稿优先（PR-033）：还原区域、字段、顺序及组件数量；匿名化只换真实值，不新增头像、字段或组件。未知内容标待确认。

参考稿结构验收（PR-034）：先保存区域树与边界清单，再选组件；完成后逐项对照区域顺序、字段、操作、通栏/缩进分隔及标题状态归属。自动运行检查不替代结构还原检查。
