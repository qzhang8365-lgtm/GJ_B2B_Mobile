来源：[Figma AI 对话流](https://www.figma.com/design/KCpwE2Lh1yCGQ86y8ckYFN?node-id=955-474)，Markdown 说明节点 1136:30。详见 [原始提取](source.json)、[映射](mapping.json)、[审计](audit.md)。

## 使用与边界

用于 AI 输出 Markdown 在回复气泡中的默认排版；不作为普通业务页面的全局排版。当前是原型基座，不是真实组件库 API，也未接入模型、消息存储或流式协议。

- 375 基准下页边距16，白色气泡内边距16、圆角12；正文16/28常规字重，当前标题16/24、600。全部设计尺寸按 px÷100 使用 rem，中西文跟随系统字体。
- 正文16/28为该组件局部样式，不覆盖全局16/24文字 Token。段落间16，标题与正文间8；关键词链接蓝色600字重。
- 无序列表带圆点，有序列表带序号。表格14/22、表头白底600；表格横向滚动，纵向全部展开，数值不截断并使用等宽数字。
- 引用编号需关联真实来源；AI提示默认收起，点击展开。处理摘要按业务可选，仅呈现可公开摘要。
- 操作区与正文分开，按需配置复制与评价；交互热区至少44×44 CSS px。
- 内容和表格不设固定高度；长链接可折行，表格仅自身横向滚动，页面不得横向溢出。

## 渲染接入

基座样式以 `.gj-m-ai-markdown` 为作用域。预览解析器仅覆盖本次基础语法，不是完整 CommonMark/GFM 实现。原始 HTML 转义，链接仅接受 HTTP(S) 或相对地址；图片不加载。代码块等未定义语法保留为普通文本，不宣称已有设计规范。正式业务使用成熟解析器和 HTML 清理机制，并单独验证扩展类型、流式分片、权限与来源跳转。

示例数据仅用于排版。头像头部、思考三态、过程区域和时间戳已包含在原型基座中；预设问题不在本次补齐范围。

列表标题24行高，说明正文28行高、上距8，说明与气泡正文左边缘对齐；独立列表项间距16。完整操作组包含赞、踩、复制、分享、重新生成、更多、来源。预览来源头像为本地示例素材。

## 补充（2026-10-15）

- 来源引用：20 的灰底圆形标记，数字 `[^1]` 或链接图标 `[^link]`，紧跟句末，可连续多个、间距 4；不带下划线。
- 列表：圆点 / 序号写在标题行首，不缩进；标题 16/24，说明 16/28 与标题左对齐，间距 8；项间距 16。
- 表格：横向滚动时底部显示 4 高的滚动指示条（Text/disable，圆角 2），内容放得下时不显示。
- AI 输出提示：单行省略 + 16 的 icf_Arrow_down（F077），点击展开全文后换为 icf_Arrow_up（F055）。
- 操作栏：赞、踩、复制、刷新、更多、来源，可选“内容由AI生成...”；分享、朗读收进「更多」（2026-10-16），一行放下。
- 推荐问题：白底卡片圆角 16、内边距 16、间距 12；标题 H4 16/24；问题项 BT_B8 底、圆角 12、内边距 12，图标 20 + 文字 H5 14/22。


- 赞 / 踩：未选用线性图标 icf_system_thumbup / thumbdown；选中后换成对应 fill 图标（thumbup-fill / thumbdown-fill），颜色 Text/blue，二者互斥，再点取消。
- 表格：各列统一左对齐（2026-10-15 设计方要求，覆盖 Figma 1098:7985 数字列右对齐）。

## Markdown 扩展元素（Figma 1097:8「Markdown 内容组件」）
- 标题：`#` 20/30（H2-CN-S）、`##` 18/26（H3-CN-S）、`###` 及以下 16/24（H4-CN-S），均 600，不跳级；正文 16/28。
- 行内代码 `code`：等宽 14/20 Medium，Background/bg_blue 底 + Text/blue，内边距 2 / 8，圆角 4；只放字段名、参数、短命令。
- 引用 `>`：浅蓝底（Blue/B01）+ 2 宽品牌蓝左线，文字 14/24 Text/Primary，内边距 12 16 12 18，圆角 8，不用斜体。
- 代码块 ```lang：Background/Background 底 + 1px Border/secondary，圆角 8，内边距 12 16，语言标签 12/18 Text/secondary，代码 14/20；不换行，横向滚动并显示滚动指示条。
- 嵌套列表：最多两级；一级 6 实心圆点 Text/Primary，二级缩进 16、6 空心圆点 Text/Tiatery（1px 描边），圆点与文字间距 8；同级间距 4。
- 任务列表 `- [ ]` / `- [x]`：复用 Checkbox（16、只读），与文字间距 8；已完成文字 Text/Tiatery；项间距 4。
- 图片 `![图注](地址)`：复用 Image 16:9，加载失败或地址无效显示占位；图注 14/22 Text/Tiatery，间距 8。只接受 http(s) 地址。
- 表格换行：单元格默认最宽 200，文字超出自动换行、顶部对齐；最多 4 行，超过时由渲染脚本按 20 递增加宽该列（GJAIMarkdown.bind）；最小宽首列 121、其余 111（含内边距）；列总宽超出容器时横向滚动。
- 表格内行内代码不换行，单元格按代码长度加宽（可超过 200），放不下时表格横滑。
- 用户气泡：宽度随文字（fit-content），最宽 283（含左右内边距 16），超出换行；靠右对齐。
