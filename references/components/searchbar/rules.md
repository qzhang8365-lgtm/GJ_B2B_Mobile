# 搜索栏 SearchBar 使用规则（移动端）

- **用途**：在列表页、选择页和数据查询入口中快速定位内容，支持关键词输入、清除和提交搜索。
- **按钮位置**：框内按钮（竖线 + 文字按钮“搜索”）用于页内检索；框外主按钮用于进入独立搜索模式或提交查询，无内容时禁用。
- **样式**：填充式默认；描边式用于表单或灰色背景上的筛选，同一区域不混用。L 高 40、M 高 32。
- **占位文案**：“搜索 + 对象/字段”，如“搜索客户名称或编号”，不要只写“请输入”。
- **触发**：短列表可实时搜索；大数据查询在提交后触发并提供加载反馈。
- **清除**：有内容时显示清除按钮（热区 ≥ 44）；清除后保留焦点并恢复默认结果，不直接退出搜索模式。
- **关键词高亮**：实时搜索结果和联想词中，匹配文字用 Text/blue 高亮，不加底色、不改字重，只高亮第一处匹配。
- **结果**：无结果时说明原因并提供下一步操作。
- **历史与联想**：仅在能提升效率时使用；敏感业务数据不得默认保存或跨用户展示。
- **iOS 字号**（2026-10-19 修订）：iOS 网页内核在输入文字小于 16px 时聚焦会自动放大页面。小程序原生页面不受影响，可用 M（14）；H5 / web-view 页面使用 M 时，viewport 加 `maximum-scale=1`，否则用 L（16）。

## 2026-10-16 设计决策
- 联想词与实时结果中，关键字用 Text/blue，不加底色、不改字重，只高亮第一处匹配（Figma search_item/suggestion）。
