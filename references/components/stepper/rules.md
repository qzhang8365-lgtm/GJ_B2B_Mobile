# 步数器 Stepper 使用规则（移动端）

- **用途**：范围明确、按固定步长变化的离散数值（数量、次数、份数）。连续范围用滑块，大范围录入用输入框；不替代开关、进度步骤或日期选择。
- **范围**：默认值、步长、最小值、最大值由业务规则明确，首次展示即为有效值。
- **加减**：每次改变一个步长；长按连续变化需限速并即时反馈。数值触发计算或请求时，处理连续点击、重复提交与异步结果覆盖。
- **直接输入**：数字键盘（inputmode=numeric）；过滤非法字符与前导零；输入中超出范围时数值区变红并提示“输入超出范围，请输入 min–max”；失焦或回车后校正到最近边界。
- **边界**：最小值只禁用减号，最大值只禁用加号，并在下方 8 用灰色显示限制说明（正常状态，不用红色）；仍可操作时不禁用整个组件。
- **整体禁用**：只用于确实不可编辑的场景，邻近位置说明原因。
- **辅助信息**：单位、库存、限额放在组件旁，不进数值区。
- **样式**：填充式默认；描边式用于灰色背景，同一区域不混用。
- **无障碍**：按钮 aria-label“减少 / 增加”；数值 input 带 aria-valuemin / aria-valuemax；热区 ≥ 44 且不覆盖数值区。
