# 索引栏 IndexBar 使用规则（移动端）

- **何时使用**：数据项较多、按首字母排序的长列表（股票、客户、机构、城市等）。数据少于一屏或无明确排序依据时不用。
- **索引项**：与分组标题一一对应，只列出有数据的字母；中文按拼音首字母归组（拼音无 I / U / V 开头）。
- **位置**：贴列表容器右侧、垂直居中，不随列表滚动；列表内容右侧为索引栏让出空间。
- **状态**：default 灰字（Text/Tiatery）；active 为当前分组，16 圆形 Brand/GJ_Blue 底、白字。
- **分组标题**：Background/Background 底，14/22 灰字，高 38，上下 8、左右 16；长列表可吸顶。
- **交互**：点按字母跳到对应分组；按住上下滑动连续切换；滚动列表时同步高亮。单项 16 高，不要求逐项 44 热区，整条索引栏响应点按与滑动，左右热区 44。

- **设计方确认（2026-10-09）**：分组标题、列表文字与分隔线缩进统一 16；索引项按最新本地组件为 48×16、左右 16。字母按实际数据生成；整条索引栏点按与滑动及至少 44px 横向热区已获确认。
