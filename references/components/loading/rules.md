# 加载态Loading

主动刷新反馈，下拉未到阈值不请求；到阈值释放后加载，完成后收起。保留已有内容，失败给原因与重试。图标20、gap4、P3 14/22 Text/Tiatery。读屏status、区域busy；减少动态效果时停止旋转。源箭头为带杆箭头，对应登记arrow-down/up。旋转使用源静态General loading图标，不手绘。演示阈值64及等待2秒为原型参数。

交互原型：卡片列表随下拉距离阻尼移动，达到64设计阈值松手进入加载并保持提示；未达阈值或取消则回弹，完成后收起并保留卡片内容。参数不代表生产手势契约。

刷新失败使用Toast展示“刷新失败，网络异常，请重新尝试。”，3秒自动消失；保留原卡片并允许重试。复用Notice/Toast基座。
