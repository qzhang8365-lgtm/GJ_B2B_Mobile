# Markdown 文章 Markdown Article 使用规则（移动端）

来源：移动端 Figma `1097:8`（Markdown 内容组件，适用于移动端文章、研报与上传内容）、`1098:8027` Markdown / Article（375 宽组合示例），2026-10-16 只读提取。原型基座：`.gj-m-markdown`（元素样式与 `.gj-m-ai-markdown` 共用）、`.gj-m-markdown-article`（文章页容器）；渲染脚本 `assets/scripts/gj-m-ai-markdown.js`（Markdown 子集，原始 HTML 转义）。

- **用途**：知识库文章、研报、资讯周报、上传文档等成段阅读内容。对话中的回答用 AI 对话流的 `.gj-m-ai-markdown`。
- **容器**：白底，上下 24、左右 16（页面边距）；块间距 16。不把文章正文再放进卡片叠加内边距。
- **字号**：正文 16/24；H1 20/30、H2 18/26、H3 及以下 16/24，Semibold；标题到下方段落 8。列表项间距 4，二级列表缩进 16。
- **元素**：段落、加粗、链接（品牌蓝）、行内代码、无序 / 有序 / 任务列表（最多两级）、引用块、代码块（语言标签 + 横滑）、表格（各列左对齐，单元格最多 4 行，超宽横滑）、分割线、图片（16:9）+ 图注 14/22。元素级规格与 AI 对话流一致。
- **与对话的差异**：对话气泡内正文行高 28、列表项间距 16；文章为 24 与 4（按 Figma 列表组件）。AI 对话流采用不同的排版逻辑，两者有意不同，不互相统一（设计方 2026-10-19 确认）。
- **安全**：只渲染 Markdown 子集；原始 HTML 一律转义，链接与图片只接受 http(s)。
- **元信息行**（2026-10-19 补充）：文章 H1 下方可放 `.gj-m-markdown-meta`：分类标签（Small，PR-005）+ 更新时间 + 阅读量等，P5 12/18 Text/Tiatery，项间距 8；标题到元信息 8，元信息到正文 16。
- **列表折行**：文章中列表项折行时悬挂缩进，续行与首行文字对齐（对话气泡保持原样）。
- **页面组合**：文章页常见结构为 导航 → 文章容器（0 级卡片 `.gj-m-card-l0`）→ 相关内容（同为 0 级卡片，卡片标题 + 通栏列表，PR-016）→ 固定底栏（收藏 / 分享 / AI 问答等，最多两个按钮，PR-009 以外的切换态用 Secondary-pressed 表示已选）。
