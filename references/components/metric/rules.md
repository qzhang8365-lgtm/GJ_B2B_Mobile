# 数据指标 Metric 使用规则（移动端）

- **重点**：优先展示对业务判断最重要的指标，避免平均分配视觉权重。
- **字号**：数字字号可在 16–24 之间选择：默认 20（N4）；需要突出时 24（`.gj-m-metric-n3`），信息密集时 18 / 16（`-n5` / `-n6`）。同一组指标字号一致。
- **数量**：并列比较 3–4 项（`.gj-m-metric-grid` / `-3`），移动端一行不超过 4 个。数值过长时换大单位（万 / 亿）或减少列数，数值不截断。
- **口径**：同一组指标单位、精度、时间口径一致；口径说明放在信息图标（`.gj-m-metric-info`，热区 44），点击用 Toast 或弹窗展示。
- **颜色**：普通数值用中性色；红（`.is-rise`）表示上涨、绿（`.is-decline`）表示下跌，只用于有明确涨跌方向的数据，不做普通强调。
- **缺失值**：暂不可用统一显示「--」（`.is-empty`），不用 0 代替；整体为空或加载失败用空状态组件。
- **对齐**：同一组指标对齐方式一致；卡片内默认居中，需要和左侧文字对齐时用左对齐。
- **绩效卡背景**：放在页面灰底上用白色绩效卡；放在白色卡片内且指标较多时，用灰色背景（`.gj-m-metric-tile-gray`）分割。两列排布用 `.gj-m-metric-tiles`。
- **趋势**：箭头 + 百分比（`.gj-m-trend`），持平显示「持平」。
- **读屏**：趋势 aria-label 写完整含义（如“较上期上涨 20%”）；信息图标 aria-label 写“××口径说明”。不只靠颜色或箭头表达涨跌。

- 趋势箭头按用户2026-10-15指定：上涨Line F087（icf_Arrow_arrow-up-large），下跌Line F0B9（icf_Arrow_arrow-down-large）；保持16尺寸和涨红跌绿。
