# 页签 Tabs · 使用规则

来源：移动端 Figma 58:680，规范说明1049:208；只读提取于2026-10-09。

Tabs

页签用于在同一页面内切换相互并列的内容区域，并持续显示当前位置，不产生新的页面层级。

基础分类

根据内容层级和视觉强度分为主级页签、次级页签、按钮式页签；分段控制用于切换视图或模式，需与导航型页签区分。

主级页签

用于页面主要内容分类，通常占满容器宽度，并通过底部指示线强调当前内容。

次级页签

用于主内容内部的二级分类，视觉更轻，适合局部内容区域切换。

按钮式页签

以圆角或矩形按钮形式切换并列内容，适合较少且标签简短的分类。

分段控制

用于切换同一数据的展示方式、范围或模式；它不是页面内容导航。

使用方法

用户点击页签后在当前位置切换内容，激活项保持可见，并保留各内容区域必要的操作状态。

1. 默认激活最常用或与当前任务最相关的页签，并同步展示对应内容。

2. 点击其他页签后切换内容和激活指示，不新增导航层级，也不自动提交用户数据。

3. 页签超过可用宽度时支持横向滚动，并自动将当前激活项滚动到可见区域。

4. 用户返回原页签时按业务需要保留筛选、输入、滚动位置或已加载内容。

使用建议

保持分类维度一致、标签简短且激活状态明确，避免用页签承载流程步骤或即时设置。

• 页签用于并列内容分类，通常建议 2–5 项；数量更多时允许横向滚动或重新梳理信息架构。

• 同一组标签必须属于同一分类维度，使用简短名词，不混入动作按钮、状态或不同层级入口。

• 一个页面通常只使用一组主级页签；需要二次分类时使用视觉更轻的次级页签。

• 按钮式页签适合少量、短标签内容；选项含义是视图或模式时应归为 Segmented Control。

• Segmented Control 切换同一内容的呈现方式，不用于页面导航；Switch 则控制立即生效的布尔设置。

• 不使用 Tabs 表达有先后顺序的任务流程，此类场景应使用 Steps 或明确的上一步、下一步操作。

• 激活状态至少通过文字样式与指示线、背景或选中块中的两种方式表达，不只依赖颜色。

• 标签宽度等分时需保证文字完整；差异较大或数量较多时使用内容自适应宽度。

• Badge 仅展示与该分类直接相关的数量或状态，不让频繁变化的数字造成布局抖动。

• 禁用页签应谨慎使用；若内容暂不可用，优先说明原因，避免出现无法理解的灰色入口。

• 切换过程中显示局部加载状态，并避免整页闪烁；已加载内容可按性能策略缓存。

• 支持辅助技术识别选中状态和页签与面板关系，并允许键盘方向键切换焦点。

## H5 基座
- 原型CSS使用gj-m-tabs、gj-m-tab及gj-m-tab-face；不是生产组件API。
- 保持单一选中项，role=tablist/tab/tabpanel、aria-selected、aria-controls、aria-labelledby与roving tabindex关联。方向键/Home/End切换并自动滚动当前项；禁用项跳过。
- 视觉高度保留源值，外层按钮至少44×44；为容纳热区，次级及分段布局可能比Figma更宽。滚动容器上下留白避免裁掉热区。
- 采用系统字体；矩形圆角6、分段内圆角6为源组件局部值，不推广为全局圆角阶梯。
- 示例内容是占位演示；面板DOM保留以保存输入。无真实请求，不假装已实现加载、业务缓存或错误处理。
- 来源差异与当前处理见audit.md；未读取或未确认的状态不得虚构。

## 预览页边距（用户确认）
375逻辑宽度下，左右统一使用space-16（0.16rem），可用内容宽343。页边距由预览页面容器提供，次级页签与内容面板不重复叠加水平padding；小屏按既有rem规则适配。

## 2026-10-16 设计决策：按钮式页签尺寸
- 按钮式页签（圆角 / 矩形）层级较低，通常跟在二级页签下作为筛选，默认 **Small**（高 28、左右 12、P5 12/18，`data-size="small"`）。
- **单独使用**（上方没有二级页签）且项数少、横向空间足够（不需横向滚动）时，优先用 **Medium**，尺寸与 Button Medium 一致：高 32、左右 16、P3 14/22（`data-size="medium"`）。
- 热区仍为 44；同一组内尺寸一致。

## 2026-10-16 设计决策：分段控制尺寸
- 分段控制（Segmented_Control）默认 **Medium**（高 32）。
- **Small**（高 28）只用于紧凑场景：放在卡片标题右侧，或图表内切换数据维度。

## 2026-10-16 设计决策：按钮式页签上下留白
- 按钮式页签放在导航下方或独立白色区域时，按钮视觉上下各留 8（到导航栏底、到白色区域底边）。热区 44 由页签按钮自身承担，容器内边距 = 8 −（44 − 按钮高）/ 2（Medium 约 2、Small 0），不叠加固定 8（之前视觉留白为 14）。

## 2026-10-16 设计决策：主级页签指示线贴底
- 主级页签栏容器不加下内边距，指示线贴在页签栏底边（与下方内容区分界处）。（“页签高 44 即热区”已被 2026-10-20 修订取代：热区改为伪元素。）

## 2026-10-19 修订：热区不占布局，卡片内按视觉边缘排布
- 起因：放进卡片时，页签按钮 44 高的热区被算进布局，分段控制还多一层上下外边距 8，卡片顶部到页签的视觉留白变成 24–32（应为卡片内边距 16）。设计方 2026-10-19 指出。
- 按钮式页签、分段控制的按钮高度 = 视觉高度，热区 44 用伪元素向上下扩展，不撑大布局（page-rules PR-010 / PR-013）。
- 页签条作为独立条带（导航下方、白色区域内）时，上下 8 由页签条内边距给出，视觉效果与 2026-10-16 决策相同。
- 放进卡片时：按钮式页签用等量负外边距抵消自身内边距（内边距保留，用来容纳热区，横滑时不被裁掉）；分段控制不加上下外边距；主级页签作为卡片首个元素时抵消文字上方的 8。与卡片边缘、相邻内容的间距只按卡片规则（内边距 16、段落间距 16 等）算一次；需要更紧的组合（如工作台 WB-4 的 8）由页面模式明确写出。
- ~~主级页签放在卡片或白色区块顶部时，区块顶边到页签文字 16……页面自建的页签区块上内边距写 8~~（已被 2026-10-20 修订取代，见下）。
- 组件不再自带外部留白后，页面要按层级明确给出间距：页签 / 分段控制作为卡片头部（代替标题）时，到下方内容用卡片标题间距 12（`--space-card-l1-title-gap`），不能贴着下方内容（2026-10-19 客户账户资产卡片，分段控制与金额只剩 4，设计方指出）。
- Figma 按钮式页签 Medium 变体由设计方自行补充，不在此跟踪。

## 2026-10-19 设计决策：页签级别按位置选（PR-023）
- 主级页签放在页面顶部 / 顶部导航下方（页面级分类），或页面内容区**第一张卡片**顶部作首个元素、代替卡片标题（2026-10-20 放开）。页签所在卡片不是第一张（如个股诊断的研报卡片在行情卡片下方）、页签上方已有标题 / 信息头、或只切换卡片内一部分内容时用次级页签。
- 同一页面主级页签只能有一组：导航下方已有主级页签时，内容区里的页签一律用次级。
- 次级页签放进卡片：基座 `.gj-m-card .gj-m-tabs[data-kind=secondary]` 去掉页签条左右 16、与卡片内容左对齐，热区用伪元素扩展不占布局，卡片顶边到文字 12（2026-10-20 由 16 改为 12）、指示线到下方内容按卡片间距 16。

## 2026-10-20 修订：主级页签单项去掉顶部 8（设计方修改 Figma 58:680）
- Figma 组件 `tabs_item/primary_tab` 去掉文字上方默认 8：单项视觉高 43 → 35（文字 24 + 间距 8 + 指示线 3），`Primary_tabs` 整条 43 → 35。`variants.json` / `schema.json` 已同步。
- 基座 `.gj-m-tab-face` 主级：`min-height .35rem; padding: 0 0 .11rem`。热区 44 用伪元素上下扩展，不撑大布局（与按钮式页签、分段控制一致）。
- 上方留白按位置给，只算一次：
  - **页面顶部 / 顶部导航下方**：页签栏上内边距 8（基座默认，`--gj-m-tabs-top: .08rem`），指示线贴页签栏底边。导航底边到页签文字 8。
  - **卡片顶部（页签作为卡片首个元素）**：页签本身不加上内边距；卡片上内边距 16 → **12**，卡片顶边到页签文字 12。基座 `.gj-m-card:has(> .gj-m-tabs[data-kind=primary]:first-child)` 已处理，页面不再写负外边距。
  - 页面自建的白色区块 / 圆角页签条，如果视觉上是“卡片顶部”，按卡片处理：区块上内边距 12，页签加 `style="--gj-m-tabs-top:0"`；如果是导航下方的通栏页签条，直接用基座默认（上 8），区块不再另加上内边距。
- 页签下方到内容：页面顶部按页面 / 卡片既有间距；卡片内按卡片段落间距 16。

## 2026-10-20 修订：次级页签在卡片顶部也用 12
- 设计方认为次级页签在卡片顶部时顶边到文字 16 偏远，改为与主级一致：页签作为卡片顶部（卡片首个元素，或卡片首个元素里的首个元素）时，卡片上内边距 16 → 12，卡片顶边到页签文字 12。页签下方到内容仍按卡片段落间距 16。
- 基座 `.gj-m-card:has(...)` 已处理主级 / 次级两种；页面不要再另写负外边距或上内边距。
- 次级页签不在卡片顶部（上方有卡片标题等）时不受影响，仍按卡片段落间距排布。
