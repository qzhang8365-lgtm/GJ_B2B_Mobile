# 图片 Image 使用规则（移动端）

- **比例**：同一列表或层级统一比例；4:3 通用内容图，16:9 横向封面，1:1 头像和方形素材。
- **裁切**：默认裁切填满并保持主体可见；证件、图表等需完整识别的图片完整展示（contain）。
- **占位**：加载前固定容器尺寸避免跳动；失败时显示统一占位图标，按需提供重新加载。失败占位、空内容、上传入口是三种语义，不混用。
- **上传入口**：虚线框 + 加号，按数量和页面密度选 120 / 160 / 240；说明格式、数量和大小限制，上传中、失败、成功都有反馈。
- **多张上传**：三列宫格（扣除卡片内边距后等分三列，间距不小于 8，图片 1:1），已上传图片右上角删除（只读展示时不放删除）；上传中显示加载图标，失败显示失败图标并允许删除重传；达到上限后隐藏上传入口。
- **预览**：深色背景全屏，支持关闭、缩放、左右切换；多图显示“当前 / 总数”。先用缩略图，不一次加载全部原图。
- **无障碍**：信息类图片提供替代文本；装饰图不重复朗读；不用图片承载必须阅读的文字。
- **触控**：可预览的缩略图整块可点；上传入口最小 120，满足热区。
