# 侧边导航栏 SideBar 使用规则（移动端）

- **何时使用**：跨模块或高频入口；不用于替代单页内的标签切换（用页签）。
- **触发与关闭**：点击页面顶部左侧菜单入口展开；点击导航项更新选中态并进入模块（导航收起）；点击主页面露出部分、关闭入口或再次点击菜单收起。
- **层级**：导航层在下，不以浮层覆盖主页面；主页面整体右移导航宽度，保留圆角 24 与左侧阴影。
- **状态栏**：系统状态栏透明覆盖在两层之上；导航层与主页面都铺到屏幕顶部，顶部内边距取容器注入的 `--safe-top`。
- **宽度**：保证图标与标题完整显示，占屏宽 64%–72%（375 下默认 264）；主页面需留出可点击区域。
- **导航项**：高 56、圆角 12、图标 24、标题 16/24 中粗；default 灰字白底，active 深字浅灰底，pressed 浅灰底；图标颜色跟随标题文字。标题过长省略。
- **选中态**：同一时刻只有一个一级导航项选中。
- **分组**：导航项较多时用分类标题（14/22 中粗灰字）分组；只滚动导航层，避免双重滚动。
- **徽标**：红点表示未读或新内容；数字表示待处理数量（徽标 S 档，16 高），超过 99 显示 99+；不用于营销提示。
