# 表格 Table 使用规则（移动端）

- **类型**：页面正文用普通表格（圆角 8，宽度适配内容区）；选择器、弹窗等临时任务用弹出层表格（投影 + 60% 蒙层），可用双行单元格放补充信息。
- **字段**：优先展示 3–4 个关键字段；更多字段横向滚动、折叠或进入详情，不把桌面端全部列压缩进一屏。
- **单元格**：上下 12、左右 16；主要内容单行（46）；需要补充信息时双行（68），两行同色；不超过两行。
- **对齐**：文本默认左对齐；同列数据格式与精度一致，需要比较大小时数值可右对齐（`.gj-m-table-num-end`）。
- **排序**：只有真正支持排序的字段显示排序图标；表头写 `aria-sort`，未排序 → 升序 → 降序循环，并反馈当前方向；图标用图标库 `icf_Arrow_caret / caret-up / caret-down`。
- **操作**：操作列最右侧并始终固定（`.gj-m-table-op`）；有内容被遮住时左侧出现投影，表格能完整展示或已滑到最右时不出现（脚本切换 `.gj-m-table-wrap.is-covered`）；保留 1–2 个高频动作，其余收进“更多”；当前项用普通文字（如“当前”）。高风险操作用危险语义并二次确认，不可用操作说明原因。
- **选择**：勾选列放最左侧（宽 52）；表头勾选直接用勾选组件的未选 / 选中 / 半选，部分选中时为半选；批量入口在表格上方显示已选数量，不在每行重复。
- **可访问性**：`th scope="col"`；勾选框 aria-label 写“选择××”；排序、说明图标、操作、勾选的热区不小于 44。
- **滚动位置**：排序、勾选等操作刷新表格时保持当前横向滚动位置，不跳回第一列。

## 2026-10-16 设计决策
- 表格弹出层（Table_Popover）圆角 8。
- Table 专用变量保留，用于斑马纹等表格专属场景；单元格底线用 Border/default。

## 表头与行标题

表头使用`thead th scope="col"`，高46、表头底色；正文行标题使用`tbody th scope="row"`，与正文td使用同样的底色、底线及上下12内边距，不继承表头底色。正文单行22行高+上下12，合计46。

2026-10-19设计方确认：表头与正文单行行高统一46（375逻辑基准），均为22行高+上下12；表头不得额外撑至48。双行单元格仍为68。
