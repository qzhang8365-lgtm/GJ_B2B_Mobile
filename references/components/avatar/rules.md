# 头像 Avatar 使用规则（移动端）

- **尺寸**：44 主要身份信息（移动端默认），36 紧凑列表、次级信息，32 对话流；不自定义其它尺寸。
- **形状**：方形圆角 8 / 圆形。同一业务场景形状和尺寸保持一致，同一列表不混用；人物常用圆形，组织、产品常用方形。
- **图片**：人物照片裁切填满（cover）并保留面部；组织 Logo 等需完整显示时用 `.gj-m-avatar-contain`。不拉伸、不压缩原图。
- **兜底**：图片缺失、加载失败或未设置时统一显示默认头像（`.is-default`），占位尺寸不变，不出现破图或空白。实现：`<img onerror>` 给外层加 `.is-default`。
- **身份文字**：头像旁保留姓名、角色等文字，不只靠图片识别；有文字时 `alt=""`，单独出现时 alt 写姓名。
- **隐私**：使用用户照片遵循隐私与授权要求，不展示无关或敏感图像。

## 2026-10-16 设计决策
- 组织 Logo 等需完整显示的图片用 Fill=logo（网站 .gj-m-avatar-contain）：白底 + 1px Border/default，图片完整显示，四周留 12%。
