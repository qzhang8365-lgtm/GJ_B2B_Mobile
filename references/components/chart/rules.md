# 图表 Chart 使用规则（移动端）

## 坐标轴

- **刻度**：Y 轴 4–6 个刻度，取整齐步长（整数或 0.5、5、10 等）；单位写在副标题或标签里，同一图表单位一致。
- **单位**：数值有单位时在坐标轴左上方写“单位：××”（`.gj-m-chart-unit`），与图表左边缘对齐；刻度标签只写数字，不在每个刻度后重复单位。
- **起点**：柱状图数值轴从 0 开始；折线图截断坐标轴时标清范围，不通过截断放大差异。
- **网格线**：默认虚线 2/2、数值 0 的基线实线（无 0 时最下方一条；1px Border/default）；也可整体实线。同一页面图表保持一致，网格线不比数据更显眼。
- **X 标签**：居中于数据点；过密时抽样（如隔一个），首末标签贴边对齐（`.is-start / .is-end`），不缩小字号、不旋转。
- **方向**：时间趋势、纵向柱状用横向网格（数值在左）；类目名称较长或排行对比用条形图 + 纵向网格（类目在左，距绘图区 12；数值 0 的竖线实线）。同一图表不同时画横竖两组网格。
- **刻度线**：类目轴（如月份、产品）可加 X 轴刻度线；时间连续的折线图一般不加。
- **布局**：一屏横向只放一个主图表；Y 标签宽度按最长刻度设置（`--gj-m-chart-y-w`，默认 28，含与绘图区的间距 8），图表放在卡片内。
- **无数据**：无数据或加载失败时不保留空坐标系，改用空状态组件。
- **可访问性**：图表容器 `role="img"` + `aria-label` 写清结论；必要时提供数据表或文字说明。

## 图例

- **何时需要**：两个及以上系列时显示图例；单系列由标题说明，不加图例。
- **取色**：所有图表系列按变量库图表色顺序取值——第 1 个系列 Chart/CH01，第 2 个 CH02，依次到 CH10，超过 10 个循环（可用 `.gj-m-chart-s1`…`-s10`）；图例与系列同色。不跳色、不自选颜色（涨跌语义除外，用 Feedback 色）。
- **标记**：形状与图表类型一致——线（折线 / 面积）、线 + 点（带数据点的折线）、圆点（饼图 / 散点）、方块（柱状 / 堆叠 / 环形）；颜色与系列一致。同一图表不混用标记。
- **位置**：折线 / 柱状图例放在图表上方、标题下方，横向排列自动换行（列距 16、行距 4）；饼图 / 环形图例放在图形右侧或下方，纵向排列（行距 8），可带数值（数值列对齐）。图例不压在图形上。
- **交互**：可点图例隐藏 / 显示系列（`aria-pressed`），隐藏态标记变灰、名称 40%；至少保留一个系列。横向热区 44；纵向热区高度取行间距，避免重叠。

## 折线图

- 用于连续时间上的趋势与多系列对比；类目对比用柱状 / 条形图，占比用环形图。
- 折线线宽 2，尖角转折（miter）、端点平头，不加数据点；不做平滑曲线。
- 风格：Default 仅折线；Fill 在折线下方加系列色渐变面积，从折线最高点 30% 到绘图区底 0%。Fill 只用于 1–2 条（Figma 仅 line=1、2 有 Fill 变体）。
- 系列 1–5 条，颜色按图表色顺序 CH01→CH10 依次取（`.gj-m-chart-s1`…），第 1 条为主系列；两条及以上加图例（线标记）。超过 5 条拆图或改为选择后查看。
- 绘制顺序：先画全部面积，再画全部折线，折线不被面积遮挡。
- 配合坐标轴使用，Y 轴取整齐刻度，折线不贴住绘图区顶边；点图例可隐藏系列（`.is-off`），至少保留一条，坐标随可见系列重算。

## 字体

- 图上的数据数字（坐标、柱顶 / 扇区标签、图例数值、数据卡数值）一律用普通 UI 字体 Regular，不加粗。
- 数字字体 GJTypeDisplay 只用于指标卡和需要突出的单个关键数值：环形中心总量、仪表完成率、单项进度大数值、进度列表右侧数值、环状进度中心值。

## 数据指示器

- 点按 / 拖动绘图区出现，吸附最近数据点，抬手保持选中，再点同一点取消；不常驻。
- 竖线 1px 虚线 2/2（Background/MK_20）贯穿绘图区；节点直径 8，系列色 + 1px 白色内描边。多系列显示同一刻度上全部可见系列节点。
- 详细数据卡与指示器同步出现：贴绘图区顶部、竖线右侧 8，靠右（> 55%）放左侧；MK_60 底、圆角 8、内边距 12、行距 4、宽 148 起，白字。单指标：名称一行 + 数值 16/24；多指标：每行名称左、数值 14/22 右，行高 22。数值用普通字体 Regular，单位 P5；隐藏的系列不列出。显示数据卡时图例不再重复带数值。

## 图表类型（参照 PC 端规则，按移动端 375 适配）

- 选型：趋势用折线 / 曲线，离散比较用柱状，构成用饼 / 环 / 百分比，多维比较用雷达，单目标达成用仪表或进度，关键词热度用词云。
- 曲线：单调三次插值，不越过相邻点范围；有突变需要读转折时用折线。
- 柱状：单系列宽 16、圆角 4；分组每柱 12、组内 4；堆叠宽 16、分段间距 2；圆角统一 4（2026-10-16）；放不下时柱宽收窄，单柱最小 8，到 8 仍放不下时减少类目或改横向；正负值共用 0 基线，正 CH01、负 CH02。纵向类目不超过 7 个，超出改横向或减少类目；数值标签 P5 12/18 Regular，堆叠只标总值。
- 饼 / 环：2–10 个指标；直径 160–180（与图例并排 160、图例在下方 180）；图例在右时左右均分留白、垂直居中，放不下自动换到下方；环内径 74%，中心数值 N3 24/36 + 单位；扇区间隔 2；饼图扇区内百分比 P3 14/22 Regular 白字，小于 8% 隐藏。
- 柱状百分比：放进 .gj-m-chart-block，标题 / 总量 → 条形 → 图例，间距 16；高 8 / 16，分段间距 2、圆角 4，合计 100%，图例带百分比。
- 雷达：3–10 维（9–10 维用 2–3 字短标签）、1–3 组，最大宽 240；可选坐标轴数值（12 点方向轴右侧，25/50/75/100，P6 10/16 Text/Tiatery）；网格 1px，数据线 2、填充 20%（可关），端点直径 6，维度标签始终显示。
- 仪表：仅半圆、3/4 圆；直径 154、弧宽 12、圆头；中心名称 P5 + 完成率 N3 24/36，间距 4，说明放仪表下方。
- 进度条：圆头轨道 8，强调 16（圆角 4）；列表每项名称行高 24、与条形间距 4、项间距 12，名称 P3 + 数值 P4 Regular；单项放进 .gj-m-chart-block，大数值 N2 → 条形 → 说明，间距 16；数值限定在有效范围。
- 环状进度：直径 88、弧宽为直径 1/10、12 点方向顺时针，中心数值 N4 20/30 + 名称 P5 12/18；多项放 .gj-m-chart-rings 居中并列、间距 24（最大 32），一行最多 3 个，窄屏等比缩小，不嵌套、不表达构成。
- 词云：强 / 中 / 弱三档权重（实色白字 16 / 20% 底 14 / 10% 底 12），文字水平，不超过 15 个，不用于精确比较。


## 2026-10-16 设计决策
- 横向正负柱：非涨跌数据正值 CH01、负值 CH02；涨跌类数据用 Feedback 色（涨 error&rise 红、跌 success&decline 绿），加 `.is-updown`。
- 词云气泡：统一用系列所属色系的 Background/BT_x20 底 + 同色系 09 号字（如 CH01 蓝 → BT_B20 + B09；CH06 绿 → BT_G20 + G09），字重 Regular；权重强弱只用气泡直径和字号（16 / 14 / 12）区分。
- 数据卡数值用普通字体 Regular，卡内不加日期标题（选中日期显示在图例上方）。
- 可点击图例换行行距 4，上下两行 44 热区重叠时按落点最近的一行判定。
- X 轴数值标签与绘图区间距统一 8。

## 2026-10-16 设计决策：横排进度列表
- 同一维度的分布或占比（星级分布、档位分布等）用 Figma `2.Chart Item / Progress` 的 default=default, style=bar（818:412）：每项一行“名称 — 条形 — 数值”，条形高 8 圆头，单色 CH01（同一系列不按项换色）。原型类 `.gj-m-chart-progress-list-inline`。
- 右侧数值不是重点突出数据时，用普通文字字体粗体（H5 14/22），不用 GJTypeDisplay 数字字体；数字字体只留给需要突出的关键数值。
- 横排进度列表需要下钻到明细对象（如某星级下的网点）时用可展开形式 `.is-expandable`：整行为按钮，行高 34（文字 22 + 行距 12，行高即热区、行间无空隙；低于 44 为密集列表例外，设计方 2026-10-16 认可），aria-expanded，第 4 列 16 展开 / 收起箭头；展开后在该行下方插入明细块（Background/Background、圆角 8、左右 12），明细每行 44、P3 14/22 + 16 右箭头进入对象详情。数量为 0 的行不可展开。同一列表一次只展开一项（2026-10-16 设计方确认）。明细块样式经设计方审阅保留。

## 2026-10-19 设计决策：图表高度与辅助区域

端到端验证「宁德时代·个股诊断」，设计方指出日K图表整体过高。坐标图绘图区沿用默认166，不代表整张卡片的上限，暂无所有图表的统一高度上限。绘图视口使用mapping.templates.plotViewport，默认1.66rem；有明确业务依据时再同步调整viewBox高度与显示高度。空的点选提示不固定预留多行；标题、图例、日期、导航自然布局，语义间距只算一次。rangeNavigator模板提供视觉布局16、原生44热区，不以热区撑高内容（PR-010/013/022）。不改动饼图、仪表等已有独立尺寸。
