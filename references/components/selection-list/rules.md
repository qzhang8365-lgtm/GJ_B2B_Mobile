# 选择列表 Selection List 使用规则（移动端）

- **用途**：从一组并列选项中选一个或多个结果；常作为选择器弹层内容。是组合模式，不替代 Radio / Checkbox：单选用 Radio 语义，多选用 Checkbox 语义。
- **选择模型**：先定单选或多选，同一组只用一种。
- **样式**：单选、多选都用尾部勾选 + 文字变蓝。单选点击即生效；多选在标题注明“可多选”，用确认式弹层底部“确定”统一提交，并显示已选数量。列表内不用方形多选框或左侧圆形勾选（方形多选框只用于表单横排、协议确认与全选）。
- **对齐**：居中只用于弹层内少量短文案的单选；勾选固定在右侧，文字保持居中。多选只用左对齐。
- **生效**：简单单选选中即生效；多选或复杂任务保留临时状态，用确认式弹层“确定”提交，“取消”/关闭/遮罩不提交；再次进入恢复已确认的结果。
- **选中反馈**：颜色 + 图标同时表达，不只靠颜色。
- **禁用**：整行 40%，保留当前状态；限制不明显时说明原因。
- **数量**：超过 6 个、需要搜索或有分组时，用选择弹层或独立选择页。
- **尾部箭头**：表示进入下一层，不与选中混用；确需组合时分开两个点击区域。
- **选项胶囊 Choice Chip**：只放简短、同维度的选项（筛选、轻量多选）；长文案或需要说明时改用列表行。默认两列网格。
- **触控**：整行可点，行高不低于 44；胶囊热区上下扩到 44。

## 2026-10-16 设计决策
- 禁用：整行 40%，文字保持原色。
- 列表末项不显示分隔线。
- 胶囊选项（Choice Chip）禁用整体 40%。

## 2026-10-16 设计决策：选项胶囊的使用范围
- 选项胶囊（Choice Chip）只用于底部弹层 / 选择弹层内；卡片或表单内的多选不默认使用胶囊，改用按钮组合（见 `components/button/rules.md` 与 `references/page-rules.md` PR-009），其次用多选框组合。

## 2026-10-20 居中弹窗内边距复核

居中弹窗也遵守列表左右16只算一次：单选列表不能放入另带16内边距的卡片body。使用Card selectionDialog组合，标题、列表、按钮为同级区块，各自只提供一次16缩进。成员选择、上传对象、开户原因等列表弹窗同规则。
