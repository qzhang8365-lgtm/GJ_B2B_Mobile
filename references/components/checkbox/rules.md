# 多选框 Checkbox 使用规则（移动端）

- **用途**：从一组相互独立的选项中选择零个、一个或多个结果，提交或确认后生效；也用于批量选择与条款确认。只能选一个用单选框；立即生效的设置用开关。
- **数量**：直接展示 2–6 个；更多时用支持多选的选择列表或独立选择页。
- **排列**：横排，间距 24，放不下时换行（行距 12）。
- **标签**：同组同一表达维度，过长自然换行；不混放动作、状态和对象。
- **点击区域**：图标 + 标签，热区高度 ≥ 44。
- **半选**：只用于父子层级汇总（如“全选”）；点击后切换为全选或全不选；不作为可提交的第三种状态。禁用项不参与全选。
- **禁用**：保留当前选择结果，必要时说明原因。
- **协议确认**：默认不勾选；协议链接单独可点，点击链接不改变勾选。
- **语义**：原生 input[type=checkbox]；半选用 indeterminate 属性；组外层 role="group" 并关联组标题。
