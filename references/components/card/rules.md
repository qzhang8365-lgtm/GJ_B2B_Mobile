# 卡片 Card 使用规则（移动端）

- **结构**：卡片 = 头部（标题 + 可选副标题）+ 内容区。白底，圆角 12，内边距 16；标题与副标题间距 4，头部与内容间距 16。内容区可放信息列表、指标、表格等任意组件。
- **标题**：卡片标题用一级（H4 16/24），简短说明主题，单行显示，过长省略；可加 20 的蓝色图标。不在标题里放数值或状态说明。
- **副标题**：补充数据口径、更新时间等（P5 12/18，Text/Tiatery），一行以内，不重复标题。
- **二级标题**：卡片内分组用二级（H5 14/22），可加蓝色竖条区分；用 `.gj-m-card-group` 包住“二级标题 + 内容”，标题与下方内容文字至少间距 8，组与组间距 16；普通字段分组不嵌套卡片；多字段独立记录形成列表时，可在一级卡片内嵌套二级卡片（PR-026）。
- **右侧操作（三选一）**：整张卡片可进入详情时用箭头，整个标题行可点（热区高 44）；只跳到列表全集时用“查看更多”；表达状态时用标签（一级 24 高，二级小号 20 高）。不同时放箭头和查看更多。
- **排布**：卡片之间间距 12，页面左右边距 16；同一页面卡片圆角、内边距一致。
- **0 级卡片**（2026-10-19 补充）：通栏，左右外边距 0、圆角 16、内边距 16（`.gj-m-card-l0`），用于信息密集、需要整宽的页面；页面首个 0 级卡片直接贴住顶部导航下沿，不留上间距，并加 `.gj-m-card-l0-top` 让上两角为直角（否则圆角两侧会露出页面底色，2026-10-19 设计方指出）。同一页面同一起始层级的模块只用一种承载方式（无卡片 / 0 级 / 一级），见 page-rules PR-016。

## 2026-10-20 统一来源：预览站页面私有写法收进基座
预览站（组件页、模式页）展示的组件只用基座 + mapping 模板，与 skill 生成同一来源；以下写法原先只写在预览页里，现已进入基座，生成页面直接使用，不在页面重复写。
- 二级卡片 `.gj-m-card-l2`：一级卡片内的灰底块，圆角 8、内边距 `--space-card-l2-padding`、内部间距 `--space-card-l2-title-gap`（h5-radius-and-containers.md）。原模式页 `.pk-block`、组件页灰色占位块改用它。
- 三级块 `.gj-m-block-l3`：格子、标签块，圆角 4、内边距 / 间距 `--space-block-l3-*`，底色浅蓝 `bt-b5`（沿用布局规范页）。
- 整卡可点 `a.gj-m-card`（模板 `card.link`）：文字继承颜色、无下划线。
- 卡片内放表单项、日历、信息网格时的首末行留白由基座处理（PR-007），页面不要再写首项 `padding-top:0` 或负外边距。

## 2026-10-20 多字段记录列表嵌套

一级卡片内有多条独立记录、每条包含名称和多项字段或操作时，允许用二级卡片 `.gj-m-card-l2` 包住每条记录。使用 `level2` 模板；圆角8、内边距12、内部间距8沿用基座，列表项之间8。成员为一级卡片，名下每家企业或账户为二级卡片。单行字段、空状态无需增加二级卡片；不在一级内重复嵌套一级。

## 2026-10-20 标题同行与紧凑记录（PR-027 / PR-028）

卡片标题默认不换行，除非业务明确要求。同行标签不得被挤到下一行，保留标签完整，标题收缩并省略；使用 header 的 right 传标签。多字段二级记录使用 record 模板：标题到信息8、字段行间距4、信息到操作8，操作右对齐，无额外 margin-top。不得叠加父 gap 与操作区 margin。普通一级卡片的操作间距仍按原规则12。

## 2026-10-20 一级卡片标准与紧凑结构（PR-029，已确认）

- 标准：复杂内容采用头部到内容16；四周内边距16、圆角12、卡片间距12。
- 紧凑：周期/上下文摘要、简短说明等内容较少时，在card模板cls传`gj-m-card-compact`；头部到内容8，相关信息行间距4，四周内边距16保持。
- 说明展开/收起可放header右侧。只有标题和单一动作时，Small按钮放header.right；hasBody=false，不创建空内容区。多个动作在窄屏放不下时保留内容区。
- 标题同行标签与操作保留，标题收缩省略；间距只由父gap或子margin一层提供，不重复叠加。标准卡片不批量改为紧凑。
- 字段行可复用`gj-m-card-record-fields`，这是Card内部组合写法；一级body可组合二级record，属于PR-026允许的跨层级承载。

二级卡片为浅灰背景，其内部标签按PR-030使用filled实底风格，避免浅填充对比不足。

卡片操作尺寸按PR-031：默认Medium，紧凑卡片同行Small，大卡片通栏/底部重点操作Large。

## 2026-10-20 同行字段文字（PR-032）
卡片信息列表中，字段名、冒号和值优先保持相同字号与行高，用三级文字色和主文字色区分。普通行按P3，紧凑行按组件已有整行选档，小屏正文至少12；不单独缩小字段名。特殊强调指标由业务明确规定。

## 2026-10-20 概要与任务分区（PR-034）
参考稿明确概要区和多个独立任务区时，用sectioned模板保留分区：概要16内边距、标题到字段8、字段4；各任务ListBar独立提供左右16/上下12，每区之前用Divider，默认左右16缩进、与内容边界对齐；通栏须有已确认例外。不要套inCard消去独立任务行的首末内边距；不因紧凑而省略原稿分区关系；线宽按当前规范，不机械照搬旧图。
