# 开关 Switch 使用规则（移动端）

- **用途**：只用于明确的开 / 关状态，切换后立即生效。多个互斥选项、内容视图或筛选条件不用开关；切换互斥内容或模式用分段控制。
- **标签**：描述被控制的功能（“消息通知”“自动保存”），不写“开关”，不重复“开启 / 关闭”。开关放在列表行尾，整行可点。
- **高风险操作**：变更不可逆、风险高或需审核时，改用按钮 + 确认流程。
- **请求反馈**：涉及网络请求时显示请求中（期间不可再次切换）；失败后恢复原状态并提示。
- **禁用**：整体 40%，保持当前状态；需有业务原因，必要时就近说明或给权限入口。
- **尺寸**：Default 48×28 用于常规设置页；Small 32×20 只用于紧凑列表；同一列表不混用。热区不小于 44×44。
- **语义**：使用 role="switch" 与 aria-checked；标签与开关关联（aria-label 或行内文字）。
