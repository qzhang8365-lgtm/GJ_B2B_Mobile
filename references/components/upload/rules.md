# 文件上传 Upload 使用规则（移动端）

- **入口**：上传按钮用次要按钮 + `icf_file_upload`，移动端默认大号 40，空间紧张用中号 32；按钮旁或下方写明可接受的类型、数量和大小。
- **即时反馈**：选择文件后立即在列表出现上传中项，显示进度条和百分比（需要判断容量时显示“已传/总大小”）。
- **取消**：上传中可取消（网站补充取消按钮，Figma 待补，见 UP-M-004）。
- **完成**：显示文件类型图标和文件名，可删除；文件名单行截断并保留扩展名；需要时补充文件大小。
- **失败**：浅红底，保留文件名并在下方写明失败原因（如“文件超过 20MB”“网络异常”）；可删除后重新上传。
- **数量上限**：达到上限后上传按钮不可用（disabled），说明文字保留。
- **删除**：已提交的文件删除属于高影响操作，必要时二次确认或提供撤销；删除后焦点回到上传按钮。
- **触控**：删除 / 取消按钮视觉 20，热区 44。
- **图片**：图片上传使用「图片 Image」的上传入口和三列宫格，不用文件列表。

- **2026-10-13 Figma更新**：文件项内部间距8；失败项保留文件名（P2、Text/Primary）和原因（P5、错误色），行间距4，失败大小采用P2错误色。文件项最小高60，真实文字行高可自然撑高。

- **失败项高度（2026-10-13 用户确认）**：最小设计高60，保留文件名24行高、原因18行高、行间距4及上下8内边距，基准下自然高62；原因换行时继续撑高，禁止固定60导致裁字。

- **多文件列表间距（2026-10-13 用户确认）**：相邻文件组件上下间距固定采用space-4（375基准4，H5为0.04rem），适用于完成、上传中和失败项；不改变头部与列表间距。

- **图标对齐（2026-10-13 Figma更新）**：图标使用20宽容器，上下2内边距，对齐首行标题24行高；失败项整体顶对齐，图标保持左上方，不随两行文字整体垂直居中。

- **状态范围（2026-10-13 用户确认）**：文件项仅保留普通、上传中、失败；不提供Pressed或按下背景反馈。上传按钮仍遵循Button自身状态规则。

- **失败项大小文字最新规则**：2026-10-13复核改为P5_CN-R 12/18，错误色保留；覆盖此前P2大小文字规则。
