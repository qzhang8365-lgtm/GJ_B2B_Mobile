# 骨架屏Skeleton

原型用于结构明确的加载场景，数据就绪后替换内容；失败和空数据切换对应反馈。文本高16、gap16、radius4，图片高160/radius8，头像54圆形。源311宽只作比例参考，页面边距由容器提供。加载区aria-busy，占位aria-hidden，不抢焦点。动效从左到右1.6s（原型选择），prefers-reduced-motion关闭。不提供真实数据服务。

## 2026-10-20 统一来源：预览站页面私有写法收进基座
预览站（组件页、模式页）展示的组件只用基座 + mapping 模板，与 skill 生成同一来源；以下写法原先只写在预览页里，现已进入基座，生成页面直接使用，不在页面重复写。
- 列表骨架：模板 `skeleton.lines` 传 `layout:"list"` → `data-layout="list"`，头像 36 在左、两行文字在右（列表 + 筛选加载态）。
