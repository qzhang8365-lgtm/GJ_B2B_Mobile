# 徽标 Badge 使用规则（移动端）

- **选用**：需要具体数量用数字徽标；只提示“有新内容”用红点。同一含义固定一种形式，不随意切换。徽标只做辅助提醒，不承载核心业务数据。
- **数字**：一位数为圆形，多位数自动加宽；超过 99 显示「99+」，全产品统一；数量为 0 时不显示。
- **尺寸**：默认 16；承载对象较大（如 40 以上入口图标）可用大号 20。
- **描边**：放在有色或复杂背景上时加白色描边。
- **位置**：徽标中心对齐承载对象右上角。单个图标（无底色）时锚点就是图标本身（如 24），不要以按钮热区或外框为基准，避免红点离图标太远；带底色的入口、头像以底块为基准；列表项放在行尾。同一列表位置、间距一致，不遮挡关键图形和文字。
- **更新**：已读、处理完成后及时减少或隐藏。
- **交互与读屏**：点击由承载对象响应，徽标本身一般不做独立入口；徽标 aria-hidden，在承载对象上说明含义与数量（如“消息，3 条未读”）。
