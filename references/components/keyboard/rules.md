# 键盘 Keyboard 使用规则（移动端）

来源：移动端 Figma `313:4600`（键盘keyboard 页），`313:8541` IOS_拼音-全键盘，375 × 327（含候选栏与底部 Home 指示区），2026-10-16 只读提取。原型基座：`.gj-m-keyboard-mock`、`.gj-m-keyboard-open`；图片 `assets/images/keyboard/ios-pinyin.png`（设计方导出 1500 × 1308，4 倍）。

- **性质**：系统键盘由操作系统绘制，H5 不实现键盘本身。键盘示意只用于原型 / 评审稿说明“键盘弹起”时的页面状态，不进入 H5 交付物，不做可点击键位。
- **尺寸**：贴屏幕底部，375 下高 327，随屏宽等比缩放（3.27rem）。
- **可见性**：聚焦的输入框及其错误提示须滚动到键盘上方，至少留 16；页面正文底部预留键盘高度（`.gj-m-keyboard-open`）。
- **固定底栏**：键盘弹起时固定底栏被键盘遮盖，不跟随上移（设计方 2026-10-16 确认，iOS / Android 表现不一时以此为准）；业务稿另有要求时按业务稿。
- **输入类型**：数字、金额、手机号用对应 `inputmode`（numeric / decimal / tel）唤起数字键盘；搜索框用 `enterkeyhint="search"`。
