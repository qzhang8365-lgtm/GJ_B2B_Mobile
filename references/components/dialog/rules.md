# 弹窗 Dialog 使用规则（移动端）

- **选用**：居中弹窗用于简短确认和高优先级结果；内容较多、含表单或连续操作用底部弹窗。普通成功提示、无需决策的信息用提示（Notice / Toast），不用弹窗。
- **触发**：只由明确的用户操作或必须处理的系统事件打开；不在弹窗中再打开弹窗，复杂分支进入独立页面或在同一弹窗内切换步骤。
- **头部**：标题一句话说明任务；正文只写决策所需信息；结果或风险时可加状态图标：默认蓝、成功绿、失败红、风险橙。
- **操作**：最多一个主要操作（右 / Primary）加一个次要操作（左 / Tertiary）；按钮文案用具体动词。危险操作写明对象和后果，打开时焦点默认放在次要操作上；提交中防止重复点击。
- **底部弹窗**：无标题时顶部放拖拽条；有标题时右侧放关闭按钮，内容可滚动时标题栏加下边线。
- **关闭**：关闭按钮、取消、系统返回结果一致；点击遮罩或下滑是否关闭按任务风险决定，有未保存内容时先确认。
- **滚动**：打开时锁定背景滚动和交互；内容超长只滚动正文，操作区保持可见。
- **无障碍**：role=dialog + aria-modal，标题关联 aria-labelledby；焦点进入弹窗并限制在内，Esc 关闭，关闭后焦点回到触发控件。
- **触控**：关闭按钮热区 44；按钮用大号 40。
- **结果提示**：操作完成后的轻提示用提示 Notice 中的 Toast（`.gj-m-toast-layer`），不用弹窗。

Panel_header支持居中与左对齐、副标题开关：标题行32，副标题22，padding上下10；无副标题52，有副标题74。副标题P3 14/22 Text/Tiatery。关闭按钮固定在主标题行右侧。

## 2026-10-19 补充：在页面中使用
- 原型基座 `.gj-m-popup` / `.gj-m-dialog` 为 `position:absolute; inset:0`，便于在预览框内展示。在整页中使用时，外层放一个 `position:fixed; inset:0` 的容器（层级高于固定底栏），并在打开时锁定 body 滚动、关闭后焦点回到触发按钮。
