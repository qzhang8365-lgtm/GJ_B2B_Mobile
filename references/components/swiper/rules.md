# 轮播 Swiper 使用规则（移动端）

- **用途**：循环轮播一组 banner 或图片，可左右滑动切换；常用于营销活动、平台公告等时效性内容入口。原「走马灯 Carousel」已合并到本组件。
- **数量**：3–5 张为宜，每张对应一个明确入口；只有 1 张时不用轮播；张数较多用数字指示器。
- **指示器**：图片偏深用 light（白点），偏浅用 dark（蓝点）；圆角卡片式 banner 把指示器放在容器外部、下方 8（dark）。指示器只表示位置，不响应点击。
- **自动轮播**：默认开启，间隔 3–5 秒；触摸时暂停，松手继续；系统开启“减少动态效果”时不播放切换动画。
- **内容**：不承载关键操作或必读信息；图片内文字避开指示器区域。
