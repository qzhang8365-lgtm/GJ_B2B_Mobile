# 单选框 Radio 使用规则（移动端）

- **用途**：必须或可以选择唯一结果的互斥选项，选项需要同时可见、便于比较。可多选用复选框；开 / 关设置用开关；即时切换视图或模式用分段控制。
- **数量**：2–5 个；更多、文本较长或需搜索时用选择器 Select。
- **排列**：横排，间距 24，放不下时换行；暂不提供纵向排列，选项较长或较多时用选择器 Select。
- **默认值**：仅在存在安全、常用或推荐选项时设置，不替用户做高风险决定。
- **标签**：并列、同维度表达，完整描述选项；不混用动作与状态。
- **点击区域**：图标 + 完整标签，热区高度 ≥ 44。
- **禁用**：整项 40%，保留当前状态；可能需要解除限制时给出原因或入口。
- **语义**：原生 input[type=radio]，同组同 name，外层 role="radiogroup" 并关联组标题。
