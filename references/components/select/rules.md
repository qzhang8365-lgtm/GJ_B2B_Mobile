# 选择器 Select 使用规则（移动端）

- **用途**：从预设选项中选择一个或多个值（状态、分类、组织、日期、级联条件等）。选择器只负责展示结果和触发，选项在底部弹层中完成。
- **选择方式**：选项少于 5 个且需直接比较时，用单选按钮平铺；日期、时间等顺序稳定的短选项用滚轮 Picker；其余用选择列表（见 Selection List）。Picker 不用于无序长名单。
- **尺寸与样式**：L 高 40、M 高 32，与同行输入框、按钮同档；填充式默认，描边式用于灰色背景，同一区域不混用。
- **占位文案**：说明选择对象（“选择客户类型”），不用含糊的“请选择”。
- **状态**：弹层打开期间显示品牌色描边、箭头朝上；结果过长省略；禁用整体 40%。
- **错误**：必填未选或校验不通过时描边 Border/error，框下方 4 给出文字提示（P5 12/18）（原因或下一步），重新选择后清除；展开弹层时不显示错误描边。
- **提交**：单选选中后立即回填并关闭；多选显示已选数量，用确认按钮统一提交，取消不提交。
- **选项多**：超过 10–15 个时提供搜索、首字母定位或分组。
- **级联**：逐级加载；上游变化后清空失效下游值并提示。
- **日期时间**：限制可选范围，必要时标明时区。
- **触控**：选择器热区高度不低于 44；弹层关闭按钮热区 44；点遮罩可关闭。

## 2026-10-16 设计决策
- 选择器占位文字 Text/Tiatery（与输入框一致）；禁用整体 40%，文字不再叠加。
- 底部弹层顶部圆角统一 16。
- Picker 弹层头部为「取消 / 保存」：滑动只改临时值，点保存提交，取消或点遮罩放弃；选择列表弹层保留关闭按钮，点选即生效。
