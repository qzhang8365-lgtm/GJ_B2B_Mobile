# 信息列表 Info List 使用规则（移动端）

- **用途**：详情页里成对展示“名称 + 内容”（订单、委托、账户、产品信息）。用 `dl / dt / dd` 结构。
- **排列**：名称短、内容短时两端对齐（默认）；名称长短不一、需要对齐阅读时左对齐（`.gj-m-info-list-inline`，名称带冒号，最小宽 92）；内容很长（地址、产品全称）时纵向（`.gj-m-info-list-vertical`）。对象信息头（客户 / 产品 / 个股卡片顶部的附属字段）用紧凑行（`.gj-m-info-list-compact` + `-plain`）：名称不设最小宽、紧跟冒号与内容，名称 P4 三级文字，内容单行省略；行尾可放“展开”等操作（PR-020）。同一张卡片里不混用排列方式。
- **宫格**：字段多且内容短（数值、状态）时用两列宫格（`.gj-m-info-grid`），放在卡片内（左右 16）；只显示一行，超出用 … 省略（可加 title 显示全文），可能超过一行的重要内容不放进宫格。
- **名称**：简短明确，不换行；需要解释口径时加信息图标（`.gj-m-info-tip`，热区 44，点击用 Toast 或弹窗说明）。
- **多行**：列表中内容过长时换行，名称与内容按行顶部对齐（名称对齐第一行），不截断关键信息；数值保持统一精度和单位。
- **无数据**：统一显示“--”，不用 0 或留空。
- **分割线**：默认每行底部 1px Border/default（上下 12），放在卡片里时最后一行可去掉分割线；字段少、整体较轻时可不带分割线（`.gj-m-info-list-plain`，上下 4）。同一张卡片里不混用。

## 2026-10-16 设计决策：放在卡片内
- 信息列表放进卡片时，首行不留上内边距、末行不留下内边距且不显示分割线；卡片头部到列表、列表到卡片底部只按卡片规则（16），不叠加行内边距。行与行之间的间距（带分割线 12+12、plain 4+4）不变。
- 基座已把 `dl` 的浏览器默认外边距清零（此前约 14 的上下外边距会让卡片内上下空白过大）。

## 2026-10-19 设计决策：对象信息头展开态

PR-020的紧凑行用于收起摘要；展开后完整已签服务为可自然换行的业务段落，不用compact强制截断。服务阶段仍用compact，并在同一行右侧放收起操作。属性标签、风测提醒、KYC和标签备注按页面层级组合，复用各自组件模板，不将这些内容伪装成多条信息列表。来源：端到端验证「客户账户」，设计方2026-10-19提供展开态截图。

## 2026-10-20 统一来源：预览站页面私有写法收进基座
预览站（组件页、模式页）展示的组件只用基座 + mapping 模板，与 skill 生成同一来源；以下写法原先只写在预览页里，现已进入基座，生成页面直接使用，不在页面重复写。
- 信息网格放进卡片：基座去掉首行上内边距、末行底部分割线，左列保留竖线；信息值里的标签垂直居中。

## 2026-10-20 同行字段文字（PR-032）
卡片信息列表中，字段名、冒号和值优先保持相同字号与行高，用三级文字色和主文字色区分。普通行按P3，紧凑行按组件已有整行选档，小屏正文至少12；不单独缩小字段名。特殊强调指标由业务明确规定。
