# 级联选择器 Cascader 使用规则（移动端）

- **用途**：有明确父子关系、需要逐层定位的数据（组织、地区、分类）。平铺选项用选择器或选择列表。
- **结构**：一级路径栏（当前项品牌蓝加粗）+ 二级胶囊选项 + 末级选择列表；路径栏和二级选项行数量多时都可横向滑动。右侧可接图标型“筛选”。底部描边只加在整个触发区底部。
- **形式**：页面内级联选到末级即生效，适合筛选和连续浏览；底部弹层级联点“确认”才回填，适合表单；层级深的体系、行业数据用分栏级联（2–3 列）。
- **路径**：始终显示已进入的层级和当前层级；点击任一级返回重选；修改上级时清除其后的失效选择。
- **完成**：到达末级完成；未到有效节点不允许提交（弹层“确认”禁用）。父级本身是有效结果时提供“选择当前层级”。
- **加载与空状态**：异步加载显示加载态，失败可重试；无下级时提示“暂无下级”或视为末级。
- **再次打开**：恢复完整路径并滚动到当前选中项。
- **复杂数据**：层级很深或需要搜索时改用独立选择页。
- **触控**：路径项高 46、宽不小于 44；胶囊热区 44；列表行 46；分栏级联行 40（相邻行无间距，按整行可点）。
