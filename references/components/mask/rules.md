# 蒙层 Mask 使用规则（移动端）

- **透明度**：弹窗、底部弹层、筛选面板、图片预览等所有模态场景统一用 60%（设计方 2026-10-14 确定）；45% 仅作备用的较轻遮挡，一般不用。
- **覆盖范围**：全屏模态覆盖整个视口（含状态栏、底部安全区）；侧边抽屉、局部浮层按容器覆盖，抽屉在蒙层之上。不留可点击空隙。
- **阻止操作**：蒙层出现期间禁止底层点击和滚动，避免焦点穿透和页面位置变化。
- **关闭**：点击蒙层是否关闭由业务风险决定，同类组件一致；确认、交易等高风险流程通常不允许点蒙层关闭。
- **层级**：同一时刻只保留一层蒙层，多个浮层复用同一背景。
- **动效与焦点**：与前景同时渐显、渐隐（0.2s），减少动效时取消；关闭后焦点回到触发入口。
