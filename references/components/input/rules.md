# 输入框 Input 使用规则（移动端）

- **用途**：录入、编辑和校验文本，用于表单、搜索与业务操作。按输入长度与信息密度选择单行或多行。
- **样式**：填充式（默认）用于名称、编号、金额等短文本；描边式适合浅色页面或紧凑表单区块。同一表单不混用两种样式。
- **尺寸**：L 高 40、16 号字（常规表单）；M 高 32、14 号字（紧凑区块）。
- **状态**：默认、输入中（品牌色边框）、已填写、禁用（40% 不透明）需稳定区分；错误信息紧邻输入框并说明修正方式。
- **标签与占位**：字段标签始终可见；占位文案只补充格式或示例。例外（2026-10-19 设计方确认）：登录、验证这类只有一两个字段、字段含义由页面标题说明的页面，可以只用占位文案，但须设置 `aria-label`。
- **键盘与格式**：金额用数字键盘，手机号分段展示，日期优先用选择器。
- **后缀操作**（2026-10-19 新增）：输入框右侧需要一个就地操作（获取验证码、发送、查询）时，用竖线分隔 + 蓝色文字按钮（`.gj-m-input-divider` + `.gj-m-input-action`），只放一个操作。点击前先校验相关字段（如账号格式），不通过时在对应字段下提示错误；发送后进入倒计时“重新获取（60s）”，期间按钮禁用，结束后变为“重新获取”。不要用独立按钮挤在输入框旁边。
- **清除**：聚焦且有内容时显示清除按钮，热区 ≥ 44。敏感信息提供显隐控制，不默认明文。
- **多行**：默认高 80，有上限时右下角显示实时字数；内容增长在内部滚动，避免遮挡底部操作。
- **iOS 字号**（2026-10-19 修订）：iOS 网页内核在输入文字小于 16px 时聚焦会自动放大页面。小程序原生页面不受影响，按设计字号；H5 / web-view 页面用小于 16 的字号时，viewport 加 `maximum-scale=1`。其它平台按设计字号。
