# Footer 页脚（移动端）

来源：Figma `138:1363`（页面 `页脚Footer` `58:4516`），2026-10-09 只读提取。结构化数据见 [`schema.json`](schema.json)，类名对应见 [`mapping.json`](mapping.json)，审计见 [`audit.md`](audit.md)。原型基座：`.gj-m-footer`（不代表真实前端组件库 API）。

## 用途

页面底部需要放置补充信息和链接时使用：内容结束提示、版权与法律信息、网站导航链接。

## 类型

| 类型 | 用途 | 规格 |
| --- | --- | --- |
| 基础页脚（label） | 内容结束告知，下方无内容或展示其他类型内容 | 上下 16；文字 P4 13/20 `Text/Tiatery`，两侧 1px `Border/default` 分隔线，线与文字间距 8 |
| 带内容的页脚（content） | 承载版权、隐私政策和使用条款等法律所需信息 | 上下 8；文字 P4 13/20 `Text/Tiatery`，居中 |
| 带链接的页脚（links） | 单个链接，点击后跳转 | 上下 8；文字 P4 13/20 `Text/blue` |
| 带链接的页脚（chips-link） | 多个链接并排 | 链接 12/18 蓝字（文字按钮 Small · blue）；链接之间为 1×16 竖线 `Border/default`（本地分割线），竖线两侧各 16；单个链接 13/20 与多个链接字号不同为设计确认 |

- 页脚宽度撑满所在容器，左右留 16 页面边距，内容水平居中，无背景。
- 多种类型组合时自上而下：结束提示 → 链接 → 版权信息，类型之间间距 8。
- 链接文字简短，一行最多 3 个；无按下态，实际点击热区至少 44×44。
- 版权符号使用“©”。
