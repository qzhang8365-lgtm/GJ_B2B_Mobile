# 批量处理列表（Batch Action List）

状态：`confirmed`（2026-10-16 设计方逐页审查后确认）。结构参考「零售银行渠道经营工作台」07-3 超时关注、07-1 上报需求，组件全部替换为当前组件库。预览：`preview/patterns/batch/index.html`。

## 适用

对一组待办逐条勾选后统一处理：超时提醒、待审批、待分配。不需要批量操作时用 list-filter。

## 页面骨架

| 区域 | 组件 | 规则 | 依据 |
| --- | --- | --- | --- |
| ① 顶部导航 | Navbar | 标题写待办集合名；与状态页签一起吸顶。 | navbar/rules.md |
| ② 状态页签 + 排序 | Tabs 按钮式 round（Medium，PR-001）+ 图标按钮 | 页签切换处理状态；右侧排序图标热区 44（BT-4）。切换页签或排序清空已选（BT-5）。 | tabs/rules.md |
| ③ 列表概要 | 文本 P5 12/18 | “共 N 项 · 排序方式”。 | 推导 |
| ④ 条目卡片 | Card + Checkbox + Tag | 每条一张卡片（BT-1）：左侧多选框，右侧类型标签 + 对象名 + 状态标签（BT-3），描述最多两行，元信息负责人 + 超时天数（红字）。卡片整体可点进入详情，多选框独立热区。已处理项多选框禁用，状态标签说明原因。 | card/rules.md、checkbox/rules.md |
| ⑤ 批量底栏 | Checkbox“全选”（半选）+ 已选数 + 主按钮 | 全选只作用于当前页签可选项；部分选中显示半选；主按钮带数量，未选禁用；无可选项时隐藏底栏（BT-2）。 | checkbox/rules.md、button/rules.md |

## 状态

| 状态 | 呈现 |
| --- | --- |
| 首次加载 | 卡片骨架屏。 |
| 执行后 | Toast“已提醒 N 位负责人”；条目改为已提醒、取消选择。 |
| 页签无条目 | Empty「暂无内容」，标题与说明写清原因（“暂无超时事项 / 所有渠道都在跟进节奏内”）。 |
| 网络异常 | Empty「网络异常」+“重新加载”。 |
