# 日历 + 记录时间轴（Calendar Records）

状态：`confirmed`（2026-10-16 设计方逐页审查后确认）。结构参考「零售银行渠道经营工作台」04-06 历史拜访记录、11 拜访记录二级页面、首页渠道拜访模块，组件全部替换为当前组件库。预览：`preview/patterns/records/index.html`。

## 适用

按日期浏览带时间的记录：拜访记录、日程、活动排期。只需按时间倒序浏览、不关心日期分布时，用列表模式（list-filter）。

## 页面骨架

| 区域 | 组件 | 规则 | 依据 |
| --- | --- | --- | --- |
| ① 顶部导航 | Navbar | 右侧可放一个筛选入口（RC-5）；与类型页签一起吸顶。 | navbar/rules.md |
| ② 类型页签 | Tabs 按钮式 round（Medium，PR-001） | 全部 / 拜访 / 活动，同时作用于日历圆点、图例与当日列表。 | tabs/rules.md |
| ③ 日历卡片 | Calendar（DatePicker 日历面板）+ Chart Legend | 只翻月（RC-1）；周日开始，行数按当月；今天蓝字，选中蓝色方块；有记录日期下方圆点按类型着色（RC-2），下方居中图例。 | datepicker/rules.md、chart 图例 |
| ④ 日期标题 | 文本 H4 16/24 | “10 月 16 日 · 2 条”；标题到卡片 12（RC-3）。 | h5 语义间距 module-title-gap |
| ⑤ 记录卡片 | Steps 纵向带时间 + Tag + 文本行 | 同日按时间正序；每条统一骨架：时间 + 类型小标签 + 对象名（H4 16/24，可点进入详情），字段用“字段名：值”文本行（P3 14/22 二级文字），下方字段按类型不同（PR-011）：<br>拜访：拜访对象 / 达成合作标签行 / 需求 + 满足状态标签（右对齐）；<br>活动：活动类型 / 活动时间（起止）/ 参与人数与开户（未开始显示报名人数）。 | steps/rules.md、tag/rules.md、info-list/rules.md |

## 状态

| 状态 | 呈现 |
| --- | --- |
| 首次加载 | 日历与列表区域骨架屏。 |
| 当日无记录 | 记录卡片内居中说明“当日暂无记录”；今天及以后日期给次按钮“新建拜访”。 |
| 网络异常 | Empty「网络异常」+“重新加载”。 |

## 已确认取值（原待确认项，2026-10-16 设计方确认按当前做法执行）

| 编号 | 问题 | 确定做法 |
| --- | --- | --- |
| RC-1 | 页面内日历是否去掉年切换。 | 记录场景只翻月。 |
| RC-2 | 类型圆点配色。 | 拜访 Feedback/warning 橙、活动 紫 P06（与类型标签同色系）。 |
| RC-3 | 日期标题样式。 | H4 16/24，上 12，下到卡片 12。 |
| RC-4 | 时间轴记录的字段写法（设计方 2026-10-16 确定）。 | 统一文本行“字段名：值”，不用信息列表；达成合作为标签行（不加字段名），需求行右侧放满足状态标签。 |
| RC-5 | 按员工筛选的入口位置（参考稿为页签行右侧下拉）。 | 导航右侧筛选图标，打开底部选择弹层。 |
