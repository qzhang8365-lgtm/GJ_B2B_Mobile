# 登录（Login）

状态：`confirmed`（2026-10-19 设计方确认为页面模式）。来源：端到端验证「国金智慧签」登录页 `planning/e2e/esign-login.html`。预览：`preview/patterns/login/index.html`。

## 适用

小程序或 H5 内部工具的登录入口：首次进入、登录失效或退出后重新登录。只有一两种登录方式；多租户 / 企业账号选择放在登录后处理。

## 页面骨架

### 登录入口

| 区域 | 组件 | 规则 | 依据 |
| --- | --- | --- | --- |
| ① 品牌区 | 图片 + 文字 | 高 44（小程序自定义导航区）；左上角 logo 28（`assets/images/gj-logo-mark.png`）+ 产品名 H4 16/24，间距 8，左距 16；右侧给小程序胶囊按钮留空，不放其他操作。 | 本模式 LG-1 |
| ② 配图 + 产品名 | 图片 + 文字 | 配图中间偏上：区域垂直居中、底部多留 48；配图 128 置于 180 的浅蓝径向光晕内；下方产品名 H2，再下一行说明 P3 14/22 Text/Tiatery（与产品名间距 8）。无专用插画时用毛玻璃图标放大（如 `fileaccess.png`）。 | 本模式 LG-2 |
| ③ 登录按钮 | Button L 通栏 | 主按钮“快捷登录”（小程序授权本机号码）在上，次按钮“手机号 / 邮箱登录”在下，间距 12，左右 16。 | button/rules.md |
| ④ 协议勾选 | Checkbox | 按钮下方 16，居中；文案 P5 12/18 Text/Secondary，协议名 Text/blue 文字链接；距底 40 + 安全区。默认不勾选。 | checkbox/rules.md |

### 手机号 / 邮箱登录

| 区域 | 组件 | 规则 | 依据 |
| --- | --- | --- | --- |
| ① 导航 | Navbar | 只有返回，回到登录入口；不写标题。 | navbar/rules.md |
| ② 页面标题 | 文本 | H2，上 24、下 24，左对齐。 | 本模式 |
| ③ 输入框 | Input L | 账号（手机号或邮箱，`inputmode="email"`）、验证码（`inputmode="numeric"`、6 位、后缀操作“获取验证码”），间距 16；只用占位文案，须有 `aria-label`（input/rules.md 标签例外）。 | input/rules.md |
| ④ 登录按钮 | Button L 通栏 | 与输入框间距 24（16 + 8）；两项都填后可点。 | button/rules.md |
| ⑤ 协议勾选 | Checkbox | 按钮下方 16，左对齐；状态与入口页共用。 | checkbox/rules.md |

## 状态与交互

| 情况 | 处理 |
| --- | --- |
| 未勾选协议时点击任一登录 | 居中弹窗“请阅读并同意协议”：不同意 / 同意并继续；同意后自动勾选并继续原操作。 |
| 获取验证码 | 先校验账号（空 / 格式错误时在账号框下提示）；通过后 Toast“验证码已发送至 138****5678”，按钮进入 60 秒倒计时“重新获取（59s）”，结束后“重新获取”。 |
| 提交校验 | 账号格式错误或验证码错误时，错误提示在对应输入框下方 4，并把焦点移到该输入框；输入修改后清除错误。 |
| 登录成功 | Toast“登录成功”后进入默认首页（底部导航第一项）。 |
| 退出登录 | 在“我的”中确认后回到登录入口。 |

## 已确认取值（2026-10-19）

| 编号 | 问题 | 确定做法 |
| --- | --- | --- |
| LG-1 | 小程序登录页的导航与品牌位置。 | 自定义导航，左上角 logo + 产品名，右侧留给胶囊按钮。 |
| LG-2 | 配图来源。 | 正式插画未提供前，用毛玻璃图标放大。 |
| LG-3 | 获取验证码的样式。 | 输入框后缀操作（`.gj-m-input-divider` + `.gj-m-input-action`），见 input/rules.md。 |
| LG-4 | 登录表单是否显示字段标签。 | 只用占位文案 + `aria-label`。 |
| LG-5 | iOS 聚焦放大。 | 小程序原生页面不处理；H5 / web-view 在 viewport 加 `maximum-scale=1`。 |
