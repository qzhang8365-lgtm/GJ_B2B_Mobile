# 详情 + 底部操作（Detail with Action Bar）

状态：`confirmed`（2026-10-16 设计方逐页审查后确认）。结构参考「零售银行渠道经营工作台」03-2 / 07-2 需求详情、04-07 拜访详情，组件全部替换为当前组件库。预览：`preview/patterns/detail/index.html`。

## 适用

查看单个业务对象并在页内完成状态更新或审批：需求、拜访、工单、委托详情。

## 页面骨架

| 区域 | 组件 | 规则 | 依据 |
| --- | --- | --- | --- |
| ① 顶部导航 | Navbar | 标题写对象类型（“需求详情”），吸顶。 | navbar/rules.md |
| ② 概要卡片 | Card + Info List（inline + plain）+ Tag | 卡片标题写对象名，右侧一个状态标签；副标题写记录人与时间。字段名带冒号左对齐，长文本换行不截断；标签可作为值（DT-1）。 | card/rules.md、info-list/rules.md、tag/rules.md |
| ③ 说明卡片 | Card + 文本块 | 大段说明放浅灰文本块（DT-2）；右侧蓝色文字按钮进入相关资料。 | card/rules.md |
| ④ 编辑卡片 | Form（Radio 横排、Textarea） | 可改字段集中在一张卡片；状态 2–3 项用单选框横排，说明用多行输入（选填，显示字数）。 | form/rules.md、radio/rules.md、input/rules.md |
| ⑤ 记录卡片 | Steps 纵向带时间 | 处理记录最新在上（DT-5），保存后插入顶部。 | steps/rules.md |
| ⑥ 固定底栏 | Form Actions（L 按钮等分，间距 12） | 次操作左、主操作右；未改动时两者禁用。只读状态不显示底栏（DT-3）。 | form/rules.md、button/rules.md |

## 状态

| 状态 | 呈现 |
| --- | --- |
| 首次加载 | 卡片骨架屏。 |
| 编辑（负责人） | 底栏“取消 / 保存更新”；改动后可用，保存中按钮文字“保存中...”并禁用，成功 Toast“已保存”，概要标签与记录同步更新。 |
| 待处理（团队长） | 不显示编辑卡片；底栏“归档 / 标记跟进”。归档建议加确认弹窗。 |
| 已归档（只读） | 顶部小号提示（plain）说明归档时间；无编辑卡片、无底栏（DT-4）。 |
| 网络异常 | Empty「网络异常」+“重新加载”。 |

## 已确认取值（原待确认项，2026-10-16 设计方确认按当前做法执行）

| 编号 | 问题 | 确定做法 |
| --- | --- | --- |
| DT-1 | 信息列表值里放标签（紧急程度、达成合作）是否允许。 | 允许小号标签，与文字同行对齐。 |
| DT-2 | 长文本块样式（无对应组件）。 | Background/Background 底、圆角 8、内边距 12、P3 14/22 二级文字。 |
| DT-3 | 固定底栏容器样式。 | 白底，上下 12、左右 16 + 底部安全区，顶部 1px Border/default；正文预留栏高。 |
| DT-4 | 只读提示用哪种提示样式。 | Notice 小号 plain 色调 + 信息图标。 |
| DT-5 | 处理记录排序（Steps 默认表达流程先后）。 | 历史记录按时间倒序，最新在上。 |
