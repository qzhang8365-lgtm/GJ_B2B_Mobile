# 分组表单提交（Grouped Form）

状态：`confirmed`（2026-10-16 设计方逐页审查后确认）。结构参考「零售银行渠道经营工作台」04-02～04-05 我要拜访，组件全部替换为当前组件库。预览：`preview/patterns/form/index.html`。

## 适用

一次提交多组信息的录入页：拜访打卡、需求上报、新建客户等。

## 页面骨架

| 区域 | 组件 | 规则 | 依据 |
| --- | --- | --- | --- |
| ① 顶部导航 | Navbar | 标题写任务动作（“我要拜访”），吸顶。 | navbar/rules.md |
| ② 上下文卡片 | ListBar（卡片模式）/ Loading / Notice 小号 warning | 自动获取的上下文（定位）预填；尾部文字按钮“重新定位”。获取中用 Loading；失败用小号警示提示并引导手动选择，不阻塞表单（FM-1）。 | listbar/rules.md、loading/rules.md、notice |
| ③ 表单卡片 | Form + Select / DatePicker / Button 按钮组合 / Radio / Textarea | 按业务决策顺序分组，每组一张卡片，卡片标题为组名；标题在上控件在下；必填红星；多选标题注明“可多选”。多选用按钮组合：Medium、宽度随文字、左对齐换行、间距 8，未选 Tertiary、选中 Secondary-pressed（PR-009）；单选 2–3 项用单选框横排。 | form/rules.md、selection-list/rules.md |
| ④ 固定底栏 | Form Actions | “保存草稿”+ 主操作（“提交打卡”）。 | form/rules.md |

## 状态与交互

| 状态 | 呈现 |
| --- | --- |
| 定位中 / 失败 | 只影响上下文卡片；失败时网点选择器为空，需手动选择。 |
| 校验失败 | 提交时校验：Toast“还有 N 项必填未完成”（FM-5），滚动到并聚焦第一项错误；错误文字在字段下方（FM-3），修改后立即消失；保留已填内容。 |
| 提交成功 | 结果卡片：成功图标 + “打卡成功” H3 + 时间地点 + 次按钮“查看拜访记录”（FM-4）。 |
| 草稿 | “保存草稿”Toast 反馈；离开未保存页面时确认保存或放弃。 |
