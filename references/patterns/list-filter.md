# 列表 + 搜索 / 筛选（List with Search & Filter）

状态：`confirmed`（2026-10-16 设计方逐页审查后确认）。预览：`preview/patterns/list-filter/index.html`。

## 适用

浏览并定位一组同类对象，再进入详情：客户列表、产品列表、待办列表、委托记录等。对象少于约 8 项且无需查找时，直接用 ListBar 或卡片，不必加搜索与筛选。

## 页面骨架（自上而下）

| 区域 | 组件 | 规则 | 依据 |
| --- | --- | --- | --- |
| ① 顶部导航 | Navbar | 容器不提供时才绘制；标题写对象集合名（“我的客户”）。有页内搜索栏时右侧不再放搜索图标。 | navbar/rules.md |
| ② 搜索区 | SearchBar L 填充式，框内无按钮 | 白底，上下 8、左右 16（页面边距）。占位“搜索 + 对象/字段”。短列表实时搜索；大数据量在提交后搜索并给加载反馈。 | searchbar/rules.md |
| ③ 筛选栏 | Filter 筛选栏，均分 | 高 46，1–4 个条件；超过 4 个时第 4 项换图标型“筛选”打开全部筛选弹层。单选选中即生效，多选点确认生效。 | filter/rules.md |
| ②③ 吸顶 | — | 搜索区与筛选栏作为一个整体吸顶（position: sticky），列表在其下滚动；筛选面板展开时遮罩覆盖列表区。 | 推导（见待确认 LF-1） |
| ④ 结果概要（可选） | 文本 | “共 N 个结果”，P5 12/18 Text/Tiatery，上 12、下 8、左右 16；搜索或筛选生效后显示，便于确认条件已作用。 | 推导（LF-2） |
| ⑤ 列表 | ListBar（通栏）或卡片列表 | 默认通栏 ListBar：前缀头像 36 / 图标 24，主文案为对象名，描述放编号与关键属性，额外内容放状态，右箭头表示可进入详情。信息超过 3 行或需要多个指标时改用卡片列表：一级卡片，卡片间距 12、左右 16。同一列表不混用两种。 | listbar/rules.md、card/rules.md、h5 语义间距 |
| ⑥ 列表尾 | Loading / 文本 | 上拉到底自动加载下一页，加载中用 Loading（加载数据中...）；没有更多时显示“没有更多了”，P5 12/18 Text/Tiatery 居中，上下 16。 | loading/rules.md；“没有更多了”为推导（LF-3） |
| ⑦ 回到顶部 | Floating Button default | 滚动超过约一屏后出现，回到顶部后隐藏；距右 16、距底 24 + 安全区（有 TabBar 时再加栏高）。 | floating-button/rules.md |
| ⑧ 底部导航（可选） | TabBar | 仅一级页面；二级列表页不放。 | tabbar/rules.md |

## 状态

| 状态 | 呈现 | 依据 |
| --- | --- | --- |
| 首次加载 | 搜索区、筛选栏照常显示；列表区用骨架屏（头像 + 文本行），数据就绪后替换。 | skeleton/rules.md |
| 下拉刷新 | 保留原列表，顶部显示 Loading（下拉刷新 → 释放刷新 → 加载数据中...）；失败用 Toast“刷新失败，网络异常，请重新尝试。”并保留原内容。 | loading/rules.md |
| 搜索 / 筛选无结果 | 列表区显示 Empty「搜索无结果」（未找到相关内容 / 请调整搜索条件后重试），主操作“清除筛选”只在筛选生效时显示。搜索区与筛选栏保留。 | empty/rules.md、filter/rules.md |
| 暂无数据 | 对象集合本身为空：Empty「暂无内容」，有新建权限时可给一个主操作。 | empty/rules.md |
| 网络异常 / 加载错误 | 首次加载失败：列表区显示 Empty「网络异常」或「加载错误」，主操作“重新加载”。分页加载失败：列表尾显示“加载失败，点击重试”（LF-4）。 | empty/rules.md |
| 无权限 | Empty「无权限」，引导联系管理员；不显示搜索与筛选。 | empty/rules.md |

## 交互

- 搜索与筛选条件同时生效（取交集）；清除搜索后保留筛选，反之亦然。
- 进入详情再返回时，保留搜索词、筛选条件与滚动位置（按业务需要，见 filter/rules.md“返回页面时按业务需要保留筛选结果”）。
- 列表项整行可点，热区即整行；禁用项整项 40% 并说明原因。
- 长名称单行省略，完整内容在详情页展示。
