# 工作台首页（Workbench Home）

状态：`confirmed`（2026-10-16 设计方逐页审查后确认）。结构参考同事项目「零售银行渠道经营工作台」01 员工版首页、06 团队版首页，组件全部替换为当前组件库。预览：`preview/patterns/workbench/index.html`。

## 适用

一级入口页：汇总待办、经营指标、当日任务与常用功能。员工 / 团队长工作台、业务首页。模块少于 3 个时不放锚点页签。

## 页面骨架（自上而下）

| 区域 | 组件 | 规则 | 依据 |
| --- | --- | --- | --- |
| ① 顶部导航 | Navbar | 容器不提供时才绘制；右侧最多一个全局操作（消息）。 | navbar/rules.md |
| ② 锚点页签 | Tabs 主级（line=fixed） | 每个页签对应一个模块，点击平滑滚动定位，滚动时自动切换当前项；≤4 个均分，>4 个横向滚动并把当前项滚入可见区。与导航一起吸顶（WB-1）。 | tabs/rules.md |
| ③ 待办模块 | Card + Tabs 按钮式 round（Medium）+ 对象摘要条目 | 按钮式页签单独使用、仅 2 项，用 Medium（同 Button Medium，见 page-rules PR-001）；切换关注类型，文字带数量（“上报需求 5”）；条目最多 3 条，底部居中蓝色文字按钮“查看全部 N 条 >”。 | card/rules.md；条目结构 WB-2、WB-3 |
| ④ 指标模块 | Card + Tabs segment（Medium，PR-002）+ Metric 灰色绩效卡 + 组合指标 + 横排进度列表（PR-003） | 副标题写数据截至时间；分段控制切换周期；卡片内分组用二级标题 + 蓝色竖条，组间距 16。 | metric/rules.md、card/rules.md、chart/rules.md |
| ⑤ 任务模块 | Card + Button 通栏主按钮 + Steps 纵向带时间 | 主操作通栏（L 40，可带 20 图标）；当日记录用时间轴，组标题右侧“查看更多”。 | button/rules.md、steps/rules.md |
| ⑥ 功能入口 | GridNav 4 列 | 每行最多 5 个；超过两行分组或进入“全部功能”。 | gridnav/rules.md |

模块卡片间距 12、左右 16（`--space-card-l1-gap`、`--space-page-margin-x`），卡片内段落间距 16（`--space-card-l1-section-gap`）。

## 状态

| 状态 | 呈现 |
| --- | --- |
| 首次加载 | 导航与锚点页签照常显示；正文用卡片骨架屏（3 张）。 |
| 单个模块失败 | 只在该模块卡片内显示“数据加载失败”+ 文字按钮“重新加载”，其他模块正常（WB-5）。 |
| 整页网络异常 | Empty「网络异常」，主操作“重新加载”。 |
| 模块无数据 | 卡片内居中说明文字（如“暂无需要关注的事项”），不用整页空状态。 |

## 已确认取值（原待确认项，2026-10-16 设计方确认按当前做法执行）

| 编号 | 问题 | 确定做法 |

| WB-3 | 首页待办展示条数与“查看全部”样式。 | 最多 3 条；蓝色小号文字按钮带右箭头，居中。 |
| WB-4 | 卡片内按钮式页签与卡片标题的间距。 | 页签热区 44，视觉上与标题、条目各约 8（抵消热区留白）。 |
| WB-6 | ~~星级分布展开后的明细块样式~~ | 已确定（2026-10-16）：浅灰底、圆角 8、左右 12；每行 44、P3 14/22 + 16 右箭头，行间 1px 分割线；一次只展开一项；列表行高 34（密集列表例外）。 |
| WB-5 | 模块内加载失败的样式。 | P5 三级文字 + 蓝色文字按钮“重新加载”，居中，上下 16。 |
