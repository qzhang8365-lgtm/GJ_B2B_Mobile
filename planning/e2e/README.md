## 发现并已补入 skill 的缺口

1. 文件展示列表放进卡片时，列表项内边距 8 与卡片 16 叠加（底部 24）→ 基座 `.gj-m-card .gj-m-file-list` 抵消；file-list/rules.md、PR-007 同类情况。
2. 纵向带时间步骤条：未发生节点的时间写法没有规定（曾写成“--”）→ `.gj-m-step-time.is-placeholder` 同格式隐藏占位；steps/rules.md。
3. 底部弹窗 / 居中弹窗基座为 `position:absolute`，整页使用时需外层 fixed 容器、锁定滚动、焦点回归 → dialog/rules.md。
4. 文章标题下的元信息行没有规格 → `.gj-m-markdown-meta`；markdown/rules.md。
5. 文章列表折行续行落到圆点下方 → 文章容器悬挂缩进（对话气泡不变）。
